## 1. Problem Statement

You get two strings `s` and `t`. Return the **shortest substring of `s`** that contains **every character of `t`, including duplicates**. If there is none, return `""`. The answer is unique.

### Example

Input:  s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"

### Constraints

- `1 <= s.length, t.length <= 10^5`
- `s` and `t` have uppercase and lowercase English letters

### What the constraints tell us (simple theory)

A **constraint** is the biggest input the judge will ever give you. A computer does about **100 million (10^8) simple steps per second**.

| Biggest input `n` | Steps you can afford | Ideas that fit |
|:---:|:---:|:---|
| up to ~5,000 | about `n^2` | Two nested loops |
| up to ~1,000,000 | about `n` | One loop, sliding window |

**For this problem:** `s` can have `10^5` characters.

- Checking every substring is up to `n(n + 1) / 2` ≈ `5 × 10^9` steps (when no window is valid, nothing stops early), and each check compares up to 52 letter counts. Far too slow.
- The sliding window: `right` moves `n` times and `left` at most `n` times, plus `m` steps to count `t`.

**How the work grows** (worst case: no valid window; counted by running code). Red bars = brute force steps, green line = sliding window steps.

## 2. Core Theory

This is the hardest problem in the topic. Three ideas must work together.

### Idea 1: count characters, do not just check if they appear

If `t` has duplicates, the window must have them too:

```text
t = "AABC"  needs  A: 2,  B: 1,  C: 1
A window with only one 'A' is NOT valid.
```

So keep a **count** for each character. A window is valid when every character of `t` appears **at least** as many times as in `t`. Extra copies and extra characters are fine: `"BANC"` has an `N` that `t` never asked for.

### Idea 2: the `formed` counter (no need to compare whole maps)

Comparing every count at every step is slow. Instead keep two numbers:

- `required` = number of **different** characters in `t` (for `"ABC"`, 3)
- `formed` = how many of them currently have **enough** copies in the window

The window is valid exactly when `formed == required`.

- **Add a character:** increase its count. If the count just became **equal** to what `t` needs, `formed += 1`. (Going from 1 to 2 copies of something that needs 1 does not count again, because `2 != 1`.)
- **Remove a character:** decrease its count. If it just dropped **below** what `t` needs, `formed -= 1`. (Removing an extra copy does not break the window.)

### Idea 3: shortest window, so record **inside** the shrink loop

This is the **shortest window** template from [209](../02.%20Basic/05.%20209.%20Minimum%20Size%20Subarray%20Sum.md):

1. Expand `right` until the window is valid.
2. **While** it is valid: record its length (if it is the shortest so far), then remove `s[left]` and move `left`.

Record **before** removing, because that is the moment the window is still valid. And use `while`, not `if`: after removing one character the window may still be valid and shorter. In our example at `right = 12`, four removals happen, and the last valid window (`"BANC"`) is the answer.

### The lecture's one-map version

The lecture uses one map `hash` with the remaining need of each character and one counter `cnt`:

- Add `s[right]`: if `hash[s[right]] > 0`, it was still needed, so `cnt += 1`. Then `hash[s[right]] -= 1` (it can go negative for extra copies).
- Valid when `cnt == len(t)` (counts every copy, not every distinct character).
- Remove `s[left]`: `hash[s[left]] += 1`; if it became `> 0`, it is needed again, so `cnt -= 1`.

Same idea, one map instead of two. Both versions are in the code below.

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| `t` longer than `s` | `"A"`, `"AA"` | `""` | Not enough characters |
| No valid window | `"ABC"`, `"D"` | `""` | Return empty when the answer stays infinite |
| Whole string | `"ABC"`, `"ABC"` | `"ABC"` | Window reaches full length |
| Extra copies to trim | `"AAABC"`, `"ABC"` | `"ABC"` | Needs `while`, not `if` |
| Duplicates in `t` | `"AAABBC"`, `"AABC"` | `"AABBC"` | Counts, not a set |
| Upper vs lower case | `"aA"`, `"A"` | `"A"` | `a` and `A` are different |
| Same as `t` | `"a"`, `"a"` | `"a"` | Smallest input |

## 4. Brute Force: Try Every Substring

### Idea

For each start, grow the substring and keep counts. As soon as it covers `t`, record it if it is the shortest and stop (longer windows from this start are worse).

### Code

```python
# Import Counter for letter counts
from collections import Counter


# Brute force: every start, grow until t is covered
class SolutionBrute:

    # Main method
    def minWindow(self, s: str, t: str) -> str:

        # Counts that t needs
        need = Counter(t)

        # Shortest valid substring so far
        best = ""

        # Every start index
        for start in range(len(s)):

            # Letter counts from start
            window = Counter()

            # Grow to the right
            for end in range(start, len(s)):

                # Count this letter
                window[s[end]] += 1

                # Covers every letter of t with enough copies
                if all(window[c] >= need[c] for c in need):

                    # Shorter than the best so far
                    if best == "" or end - start + 1 < len(best):

                        # Keep it
                        best = s[start:end + 1]

                    # Longer windows from this start cannot be shorter
                    break

        # Shortest valid substring (or "")
        return best
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2 · charset)` | Every start may scan far, and each check compares up to 52 counts |
| **Space** | `O(charset)` | The counters |

## 5. Optimal Approach: Shortest Window With `formed` and `required`

### Idea

1. Count `t` into `target_count`; `required = len(target_count)`.
2. Grow `right`; update `window_count` and `formed`.
3. While `formed == required`: record the window if shortest; remove `s[left]` (update `formed`); move `left`.
4. Return the best window, or `""`.

# Optimal: shortest window with formed / required
class Solution:

    # Main method (trace is optional and only used by the tests)
    def minWindow(self, s: str, t: str, trace: list = None) -> str:

        # Nothing to find, or not enough characters
        if not s or not t or len(t) > len(s):

            # No window can exist
            return ""

        # How many of each character t needs
        target_count = {}

        # Count t
        for ch in t:

            # One more of this character needed
            target_count[ch] = target_count.get(ch, 0) + 1

        # Number of different characters that must be satisfied
        required = len(target_count)

        # Counts inside the window
        window_count = {}

        # Different characters currently satisfied
        formed = 0

        # Left edge of the window
        left = 0

        # Length of the shortest valid window (infinity = none yet)
        min_length = float("inf")

        # Start of the shortest valid window
        min_start = 0

        # Add one character at a time
        for right in range(len(s)):

            # The character entering the window
            right_char = s[right]

            # Count it
            window_count[right_char] = window_count.get(right_char, 0) + 1

            # It just reached what t needs (== so extra copies do not count twice)
            if right_char in target_count and window_count[right_char] == target_count[right_char]:

                # One more character satisfied
                formed += 1

            # Valid: record, then try a shorter window
            while formed == required:

                # Shorter than the best so far
                if right - left + 1 < min_length:

                    # Remember its length
                    min_length = right - left + 1

                    # Remember where it starts
                    min_start = left

                # The character leaving the window
                left_char = s[left]

                # One fewer copy inside
                window_count[left_char] -= 1

                # It dropped below what t needs (< so extra copies are fine)
                if left_char in target_count and window_count[left_char] < target_count[left_char]:

                    # One fewer character satisfied
                    formed -= 1

                # Move the left edge
                left += 1

            # Save (right, left, formed) for the tests
            if trace is not None:

                # One entry per step
                trace.append((right, left, formed))

        # No valid window found
        if min_length == float("inf"):

            # Empty answer
            return ""

        # The shortest valid window
        return s[min_start:min_start + min_length]


# The lecture's version: one map of remaining need plus a counter
class SolutionOneMap:

    # Main method
    def minWindow(self, s: str, t: str) -> str:

        # Nothing to find, or not enough characters
        if not s or not t or len(t) > len(s):

            # No window can exist
            return ""

        # Remaining need of each character
        need = {}

        # Count t
        for ch in t:

            # One more of this character needed
            need[ch] = need.get(ch, 0) + 1

        # Left edge of the window
        left = 0

        # Copies of t's characters currently covered
        cnt = 0

        # Length of the shortest valid window
        min_length = float("inf")

        # Start of the shortest valid window (-1 = none)
        start_index = -1

        # Add one character at a time
        for right in range(len(s)):

            # Still needed: it covers one copy of t
            if need.get(s[right], 0) > 0:

                # One more copy covered
                cnt += 1

            # Use up one need (can go below 0 for extra copies)
            need[s[right]] = need.get(s[right], 0) - 1

            # All copies covered: record, then shrink
            while cnt == len(t):

                # Shorter than the best so far
                if right - left + 1 < min_length:

                    # Remember its length
                    min_length = right - left + 1

                    # Remember where it starts
                    start_index = left

                # Give back the leaving character's need
                need[s[left]] += 1

                # Needed again: one copy is no longer covered
                if need[s[left]] > 0:

                    # One fewer copy covered
                    cnt -= 1

                # Move the left edge
                left += 1

        # The shortest window, or "" if none
        return "" if start_index == -1 else s[start_index:start_index + min_length]

### Complexity

| Approach | Time | Space |
|:---|:---:|:---:|
| Brute force | `O(n^2 · charset)` | `O(charset)` |
| **Shortest window with `formed`** | **`O(m + n)`** (count `t`, then each pointer moves at most `n` times) | **`O(charset)`** |
| Lecture's one-map version | `O(m + n)` | `O(charset)` |

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Treating `t` as a set | Duplicates in `t` are ignored | Count every character |
| `formed += 1` whenever the count is `>=` the need | Extra copies count again; `formed` gets too big | Increase only when the count becomes **equal** to the need |
| `formed -= 1` on every removal of a needed character | Removing an extra copy wrongly breaks the window | Decrease only when it drops **below** the need |
| `if` instead of `while` | Misses shorter windows (`"AAABC"`) | `while formed == required` |
| Recording after removing | Measures a window that may be invalid | Record first, then remove |
| Returning infinity or a wrong slice when nothing is valid | Wrong answer | Return `""` when `min_length` is still infinity |

## 7. Interview Follow-ups

### Q1. Why use a `formed` counter instead of comparing two maps?

**Answer:**
- Comparing maps is `O(charset)` every step.
- `formed` changes by at most 1 per add or remove, so the validity check is `O(1)`.

### Q2. How do duplicates in `t` work?

**Answer:**
- `target_count` stores how many of each are needed.
- A character counts as satisfied only when the window has **at least** that many; `formed` changes exactly when the count crosses that line.

### Q3. What if the characters can be any Unicode?

**Answer:**
- Use dictionaries (already done). Space becomes `O(number of different characters)`.

### Q4. How do you return all minimum windows?

**Answer:**
- Keep a list. When a window equals the current minimum length, add its start; when a shorter one appears, clear the list.

### Q5. What if `t` is short but `s` is huge?

**Answer:**
- A trick: first build a filtered list of `(index, char)` for characters of `s` that are in `t`, then run the window on that list. Same answer, fewer steps when most of `s` is irrelevant.

## 8. Interview Explanation

> I count the characters of t, and let required be how many different characters it has. I use a shortest sliding window over s with a count map and a formed counter: when a character's count in the window becomes exactly what t needs, formed goes up. While formed equals required, the window is valid, so I record it if it is the shortest so far, then remove s[left], lowering formed only if that character drops below its need, and move left. Recording happens inside the loop, before the removal, and it must be a while loop to find shorter windows. Each pointer moves at most n times, so it is O(m + n) time and O(charset) space.
