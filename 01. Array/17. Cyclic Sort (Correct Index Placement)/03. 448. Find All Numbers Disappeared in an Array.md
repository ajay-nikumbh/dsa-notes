# 03. 448. Find All Numbers Disappeared in an Array

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Cyclic Sort (Correct Index Placement) | [448. Find All Numbers Disappeared in an Array](https://leetcode.com/problems/find-all-numbers-disappeared-in-an-array/) | `O(n)` | `O(1)` extra |

## 1. Problem Statement

You get an array `nums` of `n` numbers. Every number is in the range `1` to `n`.

Some numbers may appear more than once. So some numbers in `1..n` never appear.

Return all numbers in `1..n` that do not appear in `nums`.

### Example

```text
nums = [5, 4, 4, 1, 1]
n = 5

Range 1..5 = {1, 2, 3, 4, 5}
Present    = {1, 4, 5}

Output: [2, 3]
```

We use this same example in every section below.

### Constraints

- `n == nums.length`
- `1 <= n <= 10^5`
- `1 <= nums[i] <= n`
- Follow-up: no extra space (the output list does not count) and `O(n)` time

## 2. Core Theory

### What the problem really asks

"Which spots `1..n` have no owner?" There can be many such spots now, not just one.

### Why Cyclic Sort fits

Values `1..n`, so value `v` lives at **index `v - 1`**. (Pattern from scratch: [01. 268. Missing Number (Cyclic Sort)](./01.%20268.%20Missing%20Number%20%28Cyclic%20Sort%29.md). Duplicate handling: [02. 645. Set Mismatch](./02.%20645.%20Set%20Mismatch.md).)

- Swap each value home, skipping extra copies (`nums[v - 1] == v`).
- After that, every value that exists sits at its home.
- Extra copies fill the spots that nobody owns.
- So **every index `i` with `nums[i] != i + 1` means `i + 1` is missing.**

```text
After placing:

index:   0   1   2   3   4
want:   [1] [2] [3] [4] [5]
got:    [1] [1] [4] [4] [5]
             ^   ^
         2 missing, 3 missing
```

This is 645 with "one wrong spot" changed to "all wrong spots".

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| Nothing missing | `[2, 1, 3]` | `[]` | Scan finds no wrong spot |
| One element | `[1]` | `[]` | Smallest input |
| All the same | `[2, 2, 2]` | `[1, 3]` | Only one value is placed. All other spots are filler |
| Missing value is `1` | `[2, 2]` | `[1]` | Missing value at index `0` |
| Many repeats | `[1, 1, 1, 1]` | `[2, 3, 4]` | Every extra copy skips without a swap |

## 4. Brute Force: Check Every Number

### Idea

For each `x` in `1..n`, scan the array. If `x` is not there, add it to the answer.

### Code

```python
# Import List for type hints
from typing import List


# Brute force: full scan for each candidate
class SolutionBrute:

    # Main method
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:

        # Collect missing numbers here
        result = []

        # Try every number 1..n
        for x in range(1, len(nums) + 1):

            # "in" scans the whole list
            if x not in nums:

                # x never appears
                result.append(x)

        # Return all missing numbers
        return result
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | `n` candidates, each scan is `n` |
| **Space** | `O(1)` extra | Only the output list |

## 5. Better Approach: Hash Set

### Idea

Put all values in a set, then check `1..n` against it.

### Code

```python
# Better: set lookups
class SolutionBetter:

    # Main method
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:

        # All values that appear
        seen = set(nums)

        # Keep the numbers from 1..n that are not in the set
        return [x for x in range(1, len(nums) + 1) if x not in seen]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Build set, then `n` fast checks |
| **Space** | `O(n)` | The set |

## 6. Optimal Approach: Cyclic Sort

### Idea

1. Swap each value `v` to index `v - 1`, unless that index already holds `v`.
2. Scan. Every index `i` with `nums[i] != i + 1` adds `i + 1` to the answer.

### Visual Walkthrough (Story Version)

Before the arrays, let us see the idea as a story.

**The story:** 5 parking spots are numbered `1` to `5`. Five cars arrive. Each car has a spot number on its pass. Some passes were printed twice, so some spots have no car of their own. A parking guard moves cars to their own spots, then lists the spots whose owners never came.

**The rules:**

- The guard stands at one spot.
- If the car there belongs to another spot, and that spot does not already have the same pass number, swap the two cars.
- After a swap, the guard stays, because a new car arrived.
- If the right spot already has a car with this pass, this car is a copy. Leave it and walk on.
- At the end, every spot with the wrong car is a spot whose owner never came.

**How to read the pictures:** spot number on top, car's pass in `[ ]`. `^` = guard. `*` = car is in its own spot.

**Start**

```text
spot:  1    2    3    4    5
car:  [5]  [4]  [4]  [1]  [1]
       ^
```

**Step 1: guard at spot 1, car 5**

- Car 5 belongs in spot 5. Spot 5 has car 1. Swap.

```text
spot:  1    2    3    4    5
car:  [1*] [4]  [4]  [1]  [5*]
       ^
```

**Step 2: guard at spot 1, car 1**

- Car 1 is home. Walk on.

```text
spot:  1    2    3    4    5
car:  [1*] [4]  [4]  [1]  [5*]
            ^
```

**Step 3: guard at spot 2, car 4**

- Car 4 belongs in spot 4. Spot 4 has car 1. Swap.

```text
spot:  1    2    3    4    5
car:  [1*] [1]  [4]  [4*] [5*]
            ^
```

**Step 4: guard at spot 2, car 1**

- Car 1 belongs in spot 1. Spot 1 **already has car 1**. Copy. Walk on.

```text
spot:  1    2    3    4    5
car:  [1*] [1]  [4]  [4*] [5*]
                 ^
```

**Step 5: guard at spot 3, car 4**

- Spot 4 already has car 4. Copy. Walk on.

```text
spot:  1    2    3    4    5
car:  [1*] [1]  [4]  [4*] [5*]
                      ^
```

**Step 6: guard at spot 4, car 4**

- Home. Walk on.

```text
spot:  1    2    3    4    5
car:  [1*] [1]  [4]  [4*] [5*]
                           ^
```

**Step 7: guard at spot 5, car 5**

- Home. Walk on. Done.

```text
spot:  1    2    3    4    5
car:  [1*] [1]  [4]  [4*] [5*]
                                ^ (done)
```

**Step 8: list the empty owners**

- Spot 2 has car 1. Wrong. Owner 2 never came.
- Spot 3 has car 4. Wrong. Owner 3 never came.
- Answer: `[2, 3]`.

```text
spot:  1    2    3    4    5
car:  [1*] [1]  [4]  [4*] [5*]
            ^    ^
         missing 2, 3
```

**All steps at a glance**

| Step | Guard at | Car | Its spot has | Action | Cars after |
|:---:|:---:|:---:|:---:|:---|:---|
| 1 | 1 | 5 | 1 | Swap | `[1, 4, 4, 1, 5]` |
| 2 | 1 | 1 | 1 | Home, walk | `[1, 4, 4, 1, 5]` |
| 3 | 2 | 4 | 1 | Swap | `[1, 1, 4, 4, 5]` |
| 4 | 2 | 1 | 1 | Copy, walk | `[1, 1, 4, 4, 5]` |
| 5 | 3 | 4 | 4 | Copy, walk | `[1, 1, 4, 4, 5]` |
| 6 | 4 | 4 | 4 | Home, walk | `[1, 1, 4, 4, 5]` |
| 7 | 5 | 5 | 5 | Home, walk | `[1, 1, 4, 4, 5]` |
| 8 | scan | – | – | Spots 2, 3 wrong | `[2, 3]` |

**What the story teaches**

| In the story | In the code |
|:---|:---|
| Spot number | `i + 1` |
| Car's pass | `nums[i]` |
| Car's own spot | Index `v - 1` |
| "Spot already has this car" | `nums[v - 1] == v` |
| Copy car left in a stranger's spot | Duplicate value filling a gap |
| Spot whose owner never came | A missing number |

Now the same steps again, this time with the exact arrays.

### Step-by-Step Example

```text
nums = [5, 4, 4, 1, 1], n = 5
```

**Phase 1: place values**

| Step | `i` | `v = nums[i]` | `nums[v - 1]` | `== v`? | Action | `nums` after |
|:---:|:---:|:---:|:---:|:---:|:---|:---|
| 1 | 0 | 5 | `nums[4] = 1` | No | swap index 0 and 4 | `[1, 4, 4, 1, 5]` |
| 2 | 0 | 1 | `nums[0] = 1` | Yes | `i = 1` | `[1, 4, 4, 1, 5]` |
| 3 | 1 | 4 | `nums[3] = 1` | No | swap index 1 and 3 | `[1, 1, 4, 4, 5]` |
| 4 | 1 | 1 | `nums[0] = 1` | Yes | `i = 2` | `[1, 1, 4, 4, 5]` |
| 5 | 2 | 4 | `nums[3] = 4` | Yes | `i = 3` | `[1, 1, 4, 4, 5]` |
| 6 | 3 | 4 | `nums[3] = 4` | Yes | `i = 4` | `[1, 1, 4, 4, 5]` |
| 7 | 4 | 5 | `nums[4] = 5` | Yes | `i = 5` | `[1, 1, 4, 4, 5]` |

`i = 5` is not `< 5`. Loop stops. 2 swaps.

**Phase 2: scan**

| `i` | `nums[i]` | `i + 1` | Match? | `result` |
|:---:|:---:|:---:|:---:|:---|
| 0 | 1 | 1 | Yes | `[]` |
| 1 | 1 | 2 | **No** | `[2]` |
| 2 | 4 | 3 | **No** | `[2, 3]` |
| 3 | 4 | 4 | Yes | `[2, 3]` |
| 4 | 5 | 5 | Yes | `[2, 3]` |

**Answer: `[2, 3]`.**

### Code

```python
# Optimal: cyclic sort, then collect every wrong spot
class Solution:

    # Main method
    def findDisappearedNumbers(self, nums: List[int]) -> List[int]:

        # Number of elements
        n = len(nums)

        # Start at the first index
        i = 0

        # Place every value at index v - 1
        while i < n:

            # Value at the current spot
            v = nums[i]

            # Home does not hold v yet
            if nums[v - 1] != v:

                # Swap v home; stay at i
                nums[i], nums[v - 1] = nums[v - 1], nums[i]

            # Home already holds v
            else:

                # Move on
                i += 1

        # Collect the missing numbers
        result = []

        # Check every spot
        for i in range(n):

            # Owner i + 1 never came
            if nums[i] != i + 1:

                # Record it
                result.append(i + 1)

        # Return all missing numbers
        return result


# Check the example from this note, step by step

# Step 2: i = 0, value 1 is home

# Step 3: i = 1, value 4 goes to index 3

assert a == [1, 1, 4, 4, 5]

# Step 4 to 7: every value's home already holds it, no more swaps
assert all(a[a[i] - 1] == a[i] for i in range(5))

# Edge cases

assert Solution().findDisappearedNumbers([1]) == []

assert Solution().findDisappearedNumbers([2, 2]) == [1]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | At most `n` swaps plus `n` moves of `i`, then one scan |
| **Space** | `O(1)` extra | In place. The output list is not counted |

## 7. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Swap check `nums[i] != i + 1` | Two copies of one value swap forever | Check the home: `nums[v - 1] != v` |
| Returning after the first wrong spot | Only one missing number found | Scan all of `0..n-1` |
| Returning `i` instead of `i + 1` | Off by one | Spot `i` belongs to value `i + 1` |
| Inline swap with `nums[nums[i] - 1]` | Python updates `nums[i]` first, wrong cell gets written | Save `v` first |
| Counting the output list as extra space | Thinks `O(1)` is impossible | The problem says the output does not count |

## 8. Interview Follow-ups

### Q1. Can we do it with sign marking instead?

**Answer:**
- Yes. For each `v`, make `nums[abs(v) - 1]` negative.
- At the end, every index `i` that is still positive means `i + 1` never appeared.
- Also `O(n)` time and `O(1)` extra space. No swaps needed.

### Q2. Swap or sign marking: which is better?

**Answer:**
- Sign marking is a bit shorter and touches each spot only once.
- Cyclic sort is easier to extend (duplicates, first missing positive).
- Both change the input. Restore signs at the end if needed.

### Q3. What if we cannot change the input?

**Answer:**
- Then we need `O(n)` extra space, like a set or a boolean array.

### Q4. What is the most swaps that can happen?

**Answer:**
- At most `n - 1`. Each swap puts one value home for good, and once `n - 1` are home the last is home too.

### Q5. How would you also return the duplicates?

**Answer:**
- After placing, the value at each wrong spot is a duplicate copy.
- Collect `nums[i]` for each wrong spot (deduplicate if a value has 3+ copies). That is problem 442.

## 9. Interview Explanation

> Values are 1 to n, so value v belongs at index v minus 1. I do a cyclic sort: at each index, if the home of the current value does not already hold it, I swap it home and stay; otherwise I move on. Checking the home, not the current index, stops duplicates from swapping forever. After that every number that exists is at its home, and the extra copies fill the gaps. So I scan once, and every index i where nums[i] is not i plus 1 means i plus 1 is missing. It is O(n) time, because every swap places a value for good, and O(1) extra space.
