# 11. 48. Rotate Image

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Medium** | Matrix Transpose + Reverse | [48. Rotate Image](https://leetcode.com/problems/rotate-image/) | `O(n^2)` | `O(1)` |

## 1. Problem Statement

You are given an `n x n` 2D `matrix` representing an image, rotate the image by **90** degrees (clockwise).

You have to rotate the image **in-place**, which means you have to modify the input 2D matrix directly. **DO NOT** allocate another 2D matrix and do the rotation.

### Examples

```text
Input:  matrix = [[1,2,3],[4,5,6],[7,8,9]]
Output: [[7,4,1],[8,5,2],[9,6,3]]

1 2 3        7 4 1
4 5 6   ->   8 5 2
7 8 9        9 6 3
```

```text
Input:  matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
Output: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

### Constraints

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 2. Core Theory

A rotation looks like it needs a second matrix, because every element moves and moving one would clobber another. The `O(1)` space solution comes from a geometric fact: **a rotation is the composition of two reflections.**

Reflect across the main diagonal (transpose), then reflect horizontally (reverse each row). Together those two mirror operations equal a 90° clockwise turn — and each reflection is just a set of independent swaps, which is safe to do in place.

```text
         transpose            reverse each row
1 2 3    (mirror diagonal)    1 4 7    (mirror horizontal)   7 4 1
4 5 6    ───────────────>     2 5 8    ──────────────────>   8 5 2
7 8 9                         3 6 9                          9 6 3
```

Follow a single cell to see it algebraically. A clockwise rotation must send:

```text
matrix[row][col]  ->  matrix[col][n - 1 - row]
```

Track element `1` at `(0, 0)` in a 3x3:

| Step | Position | Rule applied |
|:---|:---:|:---|
| Start | `(0, 0)` | — |
| After transpose | `(0, 0)` | `(row, col) -> (col, row)` |
| After row reverse | `(0, 2)` | `(r, c) -> (r, n-1-c)` |

And the target says `(0, 0) -> (0, 3-1-0) = (0, 2)`. They agree. In general, transpose sends `(row, col)` to `(col, row)`, then reversing that row sends it to `(col, n-1-row)` — exactly the rotation formula.

**Why the transpose loop starts at `col = row + 1`.** Transposing swaps `matrix[r][c]` with `matrix[c][r]`. If you looped over the full square you would visit each pair twice and swap it back to where it started, leaving the matrix unchanged. Iterating only the strict upper triangle touches each pair once. The diagonal itself never moves, since `(r, r)` maps to itself.

**Direction is a matter of which reflection you pair with the transpose:**

| Rotation | Recipe |
|:---|:---|
| 90° clockwise | Transpose, then reverse each **row** |
| 90° anticlockwise | Transpose, then reverse each **column** |
| 180° | Reverse row order, then reverse each row |

**Recognizing the pattern:** when an in-place transformation seems to require a copy, look for a decomposition into simpler involutions (operations that are their own inverse, like reflections and reversals). Each piece can then run in place. The same trick powers the triple-reversal array rotation.

## 3. Problem Explanation

### Example

```text
Input:
matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]

Output:
matrix = [
  [7, 4, 1],

```

## 4. Core Observation

For clockwise 90-degree rotation:

```text
matrix[row][col] moves to matrix[col][n - 1 - row]
```

Example:

```text
matrix[0][0] = 1
```

After rotation:

```text
matrix[0][0] -> matrix[0][2]
```

So 1 goes to top-right.

## 5. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| 1x1 matrix | `[[1]]` | `[[1]]` | Loops never execute; nothing to swap |
| 2x2 matrix | `[[1,2],[3,4]]` | `[[3,1],[4,2]]` | Smallest case with an actual swap |
| All identical | `[[5,5],[5,5]]` | `[[5,5],[5,5]]` | Output equals input; guards against false confidence |
| Negative values | `[[-1,-2],[-3,-4]]` | `[[-3,-1],[-4,-2]]` | Only positions move; sign is irrelevant |
| Odd size | `3x3` | centre fixed | The centre cell `(1,1)` never moves |
| Even size | `4x4` | no fixed cell | There is no centre element |
| Rotating four times | any matrix | original | A useful self-check invariant |

## 6. Brute Force Solution: Use Extra Matrix

### Intuition

Create another matrix of same size.

Put every element into its rotated position.

Then copy it back to original matrix.

### Dry Run

```text
matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]
```

Using formula:

```text
new_matrix[col][n - 1 - row] = matrix[row][col]
```

Mappings:

```text
1 at (0,0) -> (0,2)
2 at (0,1) -> (1,2)
3 at (0,2) -> (2,2)

4 at (1,0) -> (0,1)
5 at (1,1) -> (1,1)
6 at (1,2) -> (2,1)

7 at (2,0) -> (0,0)
8 at (2,1) -> (1,0)
9 at (2,2) -> (2,0)
```

Final:

```text
[
  [7, 4, 1],
  [8, 5, 2],
  [9, 6, 3]
]
```

### Code

```python
# Define the class
class Solution:

    # Define the method
    def rotate(self, matrix: List[List[int]]) -> None:

        # Store the size of the square matrix
        n = len(matrix)

        # Create a new n x n matrix filled with zeroes
        rotated = [[0] * n for _ in range(n)]

        # Traverse every row
        for row in range(n):

            # Traverse every column
            for col in range(n):

                # Place current element into its rotated position
                rotated[col][n - 1 - row] = matrix[row][col]

        # Copy rotated matrix back into original matrix
        for row in range(n):

            # Traverse every column
            for col in range(n):

                # Update original matrix cell
                matrix[row][col] = rotated[row][col]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | Every cell is visited a constant number of times. |
| **Space** | `O(n^2)` | Because we use an extra matrix. |

This violates the in-place requirement of the problem.

## 7. Most Optimal Solution: Transpose + Reverse Rows

### Core Intuition

A 90-degree clockwise rotation can be done in two steps:

```text
Step 1: Transpose the matrix
Step 2: Reverse each row
```

### What is transpose?

Transpose means convert rows into columns.

```text
matrix[row][col] becomes matrix[col][row]
```

Example:

```text
Original:
[
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]
```

After transpose:

```text
[
  [1, 4, 7],
  [2, 5, 8],
  [3, 6, 9]
]
```

Now reverse each row:

```text
[1, 4, 7] -> [7, 4, 1]
[2, 5, 8] -> [8, 5, 2]
[3, 6, 9] -> [9, 6, 3]
```

Final:

```text
[
  [7, 4, 1],
  [8, 5, 2],
  [9, 6, 3]
]
```

## 8. Why This Works

For clockwise rotation:

```text
Original position: matrix[row][col]
Final position:    matrix[col][n - 1 - row]
```

After transpose:

```text
matrix[row][col] moves to matrix[col][row]
```

After reversing each row:

```text
matrix[col][row] moves to matrix[col][n - 1 - row]
```

That matches the required clockwise rotation formula.

## 9. Dry Run

```text
matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]
```

### Step 1: Transpose

Swap elements across the diagonal.

Swap `(0,1)` and `(1,0)`:

```text
[
  [1, 4, 3],
  [2, 5, 6],
  [7, 8, 9]
]
```

Swap `(0,2)` and `(2,0)`:

```text
[
  [1, 4, 7],
  [2, 5, 6],
  [3, 8, 9]
]
```

Swap `(1,2)` and `(2,1)`:

```text
[
  [1, 4, 7],
  [2, 5, 8],
  [3, 6, 9]
]
```

### Step 2: Reverse each row

```text
[1, 4, 7] -> [7, 4, 1]
[2, 5, 8] -> [8, 5, 2]
[3, 6, 9] -> [9, 6, 3]
```

Final:

```text
[
  [7, 4, 1],
  [8, 5, 2],
  [9, 6, 3]
]
```

### Code

```python
# Define the class
class Solution:

    # Define the method
    def rotate(self, matrix: List[List[int]]) -> None:

        # Store the size of the square matrix
        n = len(matrix)

        # Step 1: Transpose the matrix
        for row in range(n):

            # Start from row + 1 to avoid swapping diagonal and duplicate pairs
            for col in range(row + 1, n):

                # Swap matrix[row][col] with matrix[col][row]
                matrix[row][col], matrix[col][row] = matrix[col][row], matrix[row][col]

        # Step 2: Reverse every row
        for row in range(n):

            # Reverse current row in-place
            matrix[row].reverse()
```

## 10. Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | Because we visit matrix cells a constant number of times. |
| **Space** | `O(1)` | Because rotation is done in-place. |

## 11. Alternative Optimal Solution: Layer-by-Layer Rotation

### Intuition

Rotate the matrix layer by layer.

For each layer, move four elements at a time:

```text
top -> right
right -> bottom
bottom -> left
left -> top
```

This is also `O(n^2)` time and `O(1)` space, but transpose + reverse is easier in interviews.

### Code

```python
# Define the class
class Solution:

    # Define the method
    def rotate(self, matrix: List[List[int]]) -> None:

        # Store matrix size
        n = len(matrix)

        # Process each square layer from outside to inside
        for layer in range(n // 2):

            # First index of current layer
            first = layer

            # Last index of current layer
            last = n - 1 - layer

            # Rotate elements in current layer
            for i in range(first, last):

                # Offset from first index
                offset = i - first

                # Save top element
                top = matrix[first][i]

                # Move left element to top
                matrix[first][i] = matrix[last - offset][first]

                # Move bottom element to left
                matrix[last - offset][first] = matrix[last][last - offset]

                # Move right element to bottom
                matrix[last][last - offset] = matrix[i][last]

                # Move saved top element to right
                matrix[i][last] = top
```

## 12. Clockwise vs Anti-Clockwise

### 90 Degrees Clockwise

```text
Transpose + Reverse each row
```

Code:

```python
for row in range(n):
    for col in range(row + 1, n):
        matrix[row][col], matrix[col][row] = matrix[col][row], matrix[row][col]

for row in range(n):
    matrix[row].reverse()
```

### 90 Degrees Anti-Clockwise

```text
Transpose + Reverse each column
```

or:

```text
Reverse each row + Transpose
```

Example anti-clockwise output for:

```text
[
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]
```

is:

```text
[
  [3, 6, 9],
  [2, 5, 8],
  [1, 4, 7]
]
```

## 13. Common Mistakes

| Mistake | Why it breaks | Fix |
|:---|:---|:---|
| Transposing with `for col in range(n)` | Each pair is swapped twice, undoing itself; matrix comes back unchanged | Use `range(row + 1, n)` to touch the upper triangle only |
| Reversing rows before transposing | That composition gives anti-clockwise, not clockwise | Transpose first, then reverse rows |
| Building a new matrix and returning it | The problem demands in-place mutation and returns `None` | Mutate `matrix` directly |
| `matrix = rotated` inside the method | Rebinds the local name; the caller's list is untouched | Assign cell by cell, or use `matrix[:] = rotated` |
| Using `[[0] * n] * n` for the extra matrix | All rows are the same list object, so writes corrupt every row | `[[0] * n for _ in range(n)]` |
| Reversing columns for clockwise | Produces the anti-clockwise result | Rows for clockwise, columns for anti-clockwise |
| Assuming it generalizes to `m x n` | A non-square rotation changes the shape, so it cannot be in place | Only square matrices rotate in place |

## 14. Interview Follow-ups

**Q: How do you rotate anti-clockwise instead?**

A: Transpose, then reverse each **column** — or equivalently reverse each row first and then transpose. Same `O(n^2)` time and `O(1)` space; only the second reflection changes.

**Q: How would you rotate by 180 degrees?**

A: Reverse the order of the rows, then reverse each row. That is two reflections through perpendicular axes, which composes to a half turn. You can also apply the 90° rotation twice, but that does double the work.

**Q: What if the matrix is `m x n` rather than square?**

A: In-place becomes impossible, because the result is `n x m` and no longer fits the original allocation. You build a new matrix with `rotated[col][m - 1 - row] = matrix[row][col]`, costing `O(m*n)` space.

**Q: Why start the transpose loop at `row + 1`?**

A: The swap is symmetric. Visiting both `(r, c)` and `(c, r)` swaps the same pair twice and restores the original. The strict upper triangle visits each pair exactly once, and the diagonal needs no work since it maps to itself.

**Q: Which approach would you write in an interview, transpose-reverse or layer-by-layer?**

A: Transpose plus reverse. Both are `O(n^2)` time and `O(1)` space, but the layer version needs four index expressions with an offset that is easy to get wrong under pressure. Transpose-reverse is two short loops and its correctness argument is one line.

**Q: How would you test it without hardcoding every expected matrix?**

A: Rotate four times and assert the matrix equals the original — a property that is cheap to check and catches most index errors. Pair that with a reference implementation using the extra-matrix formula.

## 15. Interview Explanation

> To rotate the matrix 90 degrees clockwise in-place, I first transpose the matrix, which swaps `matrix[i][j]` with `matrix[j][i]`. Then I reverse every row. This works because an element originally at `(row, col)` should finally go to `(col, n - 1 - row)`. Transpose moves it to `(col, row)`, and reversing the row moves it to `(col, n - 1 - row)`. The time complexity is `O(n^2)` and space complexity is `O(1)`.

## 16. Verify

```python
# Import type hint for list-of-lists parameter
from typing import List

# Import copy for making deep copies of test matrices
import copy


# Define the in-place rotate function
def rotate(matrix: List[List[int]]) -> None:

    # Store the size of the square matrix
    n = len(matrix)
    # Step 1: transpose (upper triangle only)
    for row in range(n):

        # Start from row + 1 to avoid swapping diagonal and duplicate pairs
        for col in range(row + 1, n):

            # Swap matrix[row][col] with matrix[col][row]
            matrix[row][col], matrix[col][row] = matrix[col][row], matrix[row][col]
    # Step 2: reverse each row
    for row in range(n):

        # Reverse current row in-place
        matrix[row].reverse()


# Define a helper that rotates a deep copy and returns it
def run(grid):

    # Deep copy so the caller's original grid is untouched
    m = copy.deepcopy(grid)

    # Rotate the copy in-place
    rotate(m)

    # Return the rotated copy
    return m


# LeetCode examples: standard 3x3 and 4x4 rotations
assert run([[1, 2, 3], [4, 5, 6], [7, 8, 9]]) == [[7, 4, 1], [8, 5, 2], [9, 6, 3]]
assert run([[5, 1, 9, 11], [2, 4, 8, 10], [13, 3, 6, 7], [15, 14, 12, 16]]) == [
    [15, 13, 2, 5],
    [14, 3, 4, 1],
    [12, 6, 8, 9],
    [16, 7, 10, 11],
]

# 1x1 matrix: loops never execute; nothing to swap
assert run([[1]]) == [[1]]

# 2x2 matrix: smallest case with an actual swap
assert run([[1, 2], [3, 4]]) == [[3, 1], [4, 2]]

# All identical: output equals input; guards against false confidence
assert run([[5, 5], [5, 5]]) == [[5, 5], [5, 5]]

# Negative values: only positions move; sign is irrelevant
assert run([[-1, -2], [-3, -4]]) == [[-3, -1], [-4, -2]]

# Cross-check against the extra-matrix formula
def reference(grid):

    # Store the size of the square matrix
    n = len(grid)

    # Create a fresh output matrix of the same size
    out = [[0] * n for _ in range(n)]

    # Walk every row of the input
    for row in range(n):

        # Walk every column of the input
        for col in range(n):

            # Place each element at its rotated destination
            out[col][n - 1 - row] = grid[row][col]

    # Return the reference-rotated matrix
    return out
```
