# 03. 48. Rotate Image

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Medium** | Matrix Transpose + Reverse | [48. Rotate Image](https://leetcode.com/problems/rotate-image/) | `O(n^2)` | `O(1)` |

## 1. Problem Statement

You get an `n x n` matrix that stands for an image.

Rotate the image by **90 degrees clockwise**.

You must do it **in place**. Do not make another 2D matrix.

### Example

```text
matrix = [[1,2,3],[4,5,6],[7,8,9]]

 1 2 3          7 4 1
 4 5 6   --->   8 5 2
 7 8 9          9 6 3

Output: [[7,4,1],[8,5,2],[9,6,3]]
```

We use this same example in every section below.

LeetCode example 2:

```text
[[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
-> [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

### Constraints

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 2. Core Theory

### Where does each cell go?

For a clockwise turn:

```text
matrix[row][col]  moves to  matrix[col][n - 1 - row]
```

The top row becomes the right column. The left column becomes the top row.

### Why moving cells one by one is hard

If we move `1` to its new spot, we overwrite `3`. Then `3` is lost. A copy would fix that, but the problem says no copy.

### The trick: a turn = two mirror flips

1. **Transpose** (mirror across the main diagonal): `(row, col) -> (col, row)`.
2. **Reverse each row** (mirror left-right): `(r, c) -> (r, n - 1 - c)`.

Put together: `(row, col) -> (col, row) -> (col, n - 1 - row)`. That is exactly the turn.

Each flip is just pairs of swaps, and swaps are safe in place.

```text
         transpose               reverse each row
1 2 3    (mirror diagonal)  1 4 7   (mirror left-right)   7 4 1
4 5 6    --------------->   2 5 8   ------------------>   8 5 2
7 8 9                       3 6 9                         9 6 3
```

### Why the transpose loop starts at `col = row + 1`

- Swapping `(r, c)` with `(c, r)` is one pair.
- If we loop over the full square, we visit each pair twice and swap it back.
- So we only visit the part above the diagonal. The diagonal itself never moves.

### Other directions

| Turn | Recipe |
|:---|:---|
| 90 clockwise | Transpose, then reverse each **row** |
| 90 anticlockwise | Transpose, then reverse each **column** |
| 180 | Reverse the row order, then reverse each row |

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| `1 x 1` | `[[5]]` | `[[5]]` | Nothing moves. Loops do no swaps |
| `2 x 2` | `[[1,2],[3,4]]` | `[[3,1],[4,2]]` | Smallest real turn. One transpose swap |
| Even size | 4 x 4 example | see above | No center cell |
| Odd size | 3 x 3 example | see above | Center `5` stays put |
| Negative values | `[[-1,-2],[-3,-4]]` | `[[-3,-1],[-4,-2]]` | Values do not matter, only positions |
| Four turns | any | the original | Good self-check |

## 4. Brute Force: Use an Extra Matrix

### Idea

Make a new `n x n` matrix. Put each cell at `rotated[col][n - 1 - row]`. Then copy it back into `matrix`. This breaks the "no extra matrix" rule, but it is easy to trust.

### Code

```python
# Import List for type hints
from typing import List


# Brute force: build the rotated picture in a new matrix
class SolutionBrute:

    # Main method
    def rotate(self, matrix: List[List[int]]) -> None:

        # Size of the matrix
        n = len(matrix)

        # New empty matrix (a fresh list for every row)
        rotated = [[0] * n for _ in range(n)]

        # Go through every row
        for row in range(n):

            # Go through every column
            for col in range(n):

                # Put the cell at its turned spot
                rotated[col][n - 1 - row] = matrix[row][col]

        # Copy every row back into the original matrix
        for row in range(n):

            # Replace the row contents in place
            matrix[row][:] = rotated[row]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | Visit every cell twice |
| **Space** | `O(n^2)` | The extra matrix |

## 5. Optimal Approach: Transpose, then Reverse Each Row

### Idea

1. For every `row`, for every `col > row`: swap `matrix[row][col]` and `matrix[col][row]`.
2. Reverse every row.

### Visual Walkthrough (Story Version)

**The story:** a photo is made of 9 square tiles stuck on a table. We want to turn the photo a quarter turn to the right. But the table has no extra space. We can only **swap two tiles** at a time.

**The plan:**

- **Part A (fold on the diagonal):** imagine a line from the top-left corner to the bottom-right corner. Every tile above the line swaps with its twin below the line. Tiles on the line stay.
- **Part B (flip each shelf):** each row is a shelf. Turn every shelf around, so left becomes right.

**How to read the pictures:** `\` marks the diagonal line. `( )` marks the two tiles being swapped.

**Start**

```text
 [1] [2] [3]
 [4] [5] [6]
 [7] [8] [9]
  \
   diagonal: 1, 5, 9 never move in Part A
```

**Part A, swap 1: tile (0,1) with tile (1,0)**

```text
 [1] (2) [3]          [1] (4) [3]
 (4) [5] [6]   --->   (2) [5] [6]
 [7] [8] [9]          [7] [8] [9]
```

`2` and `4` trade places.

**Part A, swap 2: tile (0,2) with tile (2,0)**

```text
 [1] [4] (3)          [1] [4] (7)
 [2] [5] [6]   --->   [2] [5] [6]
 (7) [8] [9]          (3) [8] [9]
```

`3` and `7` trade places.

**Part A, swap 3: tile (1,2) with tile (2,1)**

```text
 [1] [4] [7]          [1] [4] [7]
 [2] [5] (6)   --->   [2] [5] (8)
 [3] (8) [9]          [3] (6) [9]
```

`6` and `8` trade places. Part A is done. Rows are now the old columns.

**Part B, shelf 0: flip `[1, 4, 7]`**

```text
 [7] [4] [1]   <- flipped
 [2] [5] [8]
 [3] [6] [9]
```

**Part B, shelf 1: flip `[2, 5, 8]`**

```text
 [7] [4] [1]
 [8] [5] [2]   <- flipped
 [3] [6] [9]
```

**Part B, shelf 2: flip `[3, 6, 9]`**

```text
 [7] [4] [1]
 [8] [5] [2]
 [9] [6] [3]   <- flipped
```

The photo is turned a quarter to the right.

**All steps at a glance**

| Step | Action | Matrix after |
|:---:|:---|:---|
| start | – | `[[1,2,3],[4,5,6],[7,8,9]]` |
| A1 | swap `(0,1)` and `(1,0)` | `[[1,4,3],[2,5,6],[7,8,9]]` |
| A2 | swap `(0,2)` and `(2,0)` | `[[1,4,7],[2,5,6],[3,8,9]]` |
| A3 | swap `(1,2)` and `(2,1)` | `[[1,4,7],[2,5,8],[3,6,9]]` |
| B1 | flip row 0 | `[[7,4,1],[2,5,8],[3,6,9]]` |
| B2 | flip row 1 | `[[7,4,1],[8,5,2],[3,6,9]]` |
| B3 | flip row 2 | `[[7,4,1],[8,5,2],[9,6,3]]` |

**What the story teaches**

| In the story | In the code |
|:---|:---|
| Tile | `matrix[row][col]` |
| Diagonal line | cells where `row == col` |
| Swap with the twin across the line | `matrix[row][col], matrix[col][row] = ...` |
| Only tiles above the line start a swap | `for col in range(row + 1, n)` |
| Flip a shelf | `matrix[row].reverse()` |
| No extra table space | `O(1)` extra memory |

Now the same steps again, with the exact loop values.

### Step-by-Step Example

```text
n = 3
matrix = [[1, 2, 3],
          [4, 5, 6],
          [7, 8, 9]]
```

**Part A: transpose**

`row = 0`, `col` goes over `range(1, 3)`:

1. `col = 1`: swap `matrix[0][1] = 2` and `matrix[1][0] = 4`.
   `matrix = [[1, 4, 3], [2, 5, 6], [7, 8, 9]]`
2. `col = 2`: swap `matrix[0][2] = 3` and `matrix[2][0] = 7`.
   `matrix = [[1, 4, 7], [2, 5, 6], [3, 8, 9]]`

`row = 1`, `col` goes over `range(2, 3)`:

3. `col = 2`: swap `matrix[1][2] = 6` and `matrix[2][1] = 8`.
   `matrix = [[1, 4, 7], [2, 5, 8], [3, 6, 9]]`

`row = 2`, `col` goes over `range(3, 3)`: empty, no swap.

**Part B: reverse each row**

4. `row = 0`: `[1, 4, 7]` becomes `[7, 4, 1]`.
   `matrix = [[7, 4, 1], [2, 5, 8], [3, 6, 9]]`
5. `row = 1`: `[2, 5, 8]` becomes `[8, 5, 2]`.
   `matrix = [[7, 4, 1], [8, 5, 2], [3, 6, 9]]`
6. `row = 2`: `[3, 6, 9]` becomes `[9, 6, 3]`.
   `matrix = [[7, 4, 1], [8, 5, 2], [9, 6, 3]]`

**Check one cell with the formula:** `1` was at `(0, 0)`. It should go to `(0, 3 - 1 - 0) = (0, 2)`. It is at `(0, 2)`.

### Code

```python
# Solution for 48. Rotate Image
class Solution:

    # Main method
    def rotate(self, matrix: List[List[int]]) -> None:

        # Size of the matrix
        n = len(matrix)

        # Part A: go through every row
        for row in range(n):

            # Only columns to the right of the diagonal
            for col in range(row + 1, n):

                # Swap the cell with its twin across the diagonal
                matrix[row][col], matrix[col][row] = matrix[col][row], matrix[row][col]

        # Part B: go through every row
        for row in range(n):

            # Flip the row left to right
            matrix[row].reverse()
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | Each cell is touched a fixed number of times |
| **Space** | `O(1)` | Only swaps inside the matrix |

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Transpose loop `for col in range(n)` | Each pair is swapped twice. Nothing changes | Use `range(row + 1, n)` |
| Reverse rows first, then transpose | Gives an anticlockwise turn | Transpose first |
| `matrix = rotated` inside the method | Only changes the local name. Caller sees no change | Change cells in place, or `matrix[:] = rotated` |
| `[[0] * n] * n` for the extra matrix | All rows are one shared list | `[[0] * n for _ in range(n)]` |
| Trying this on an `m x n` matrix | The shape changes, so it cannot be in place | Only square matrices turn in place |

## 7. Interview Follow-ups

### Q1. How do you rotate anticlockwise?

**Answer:**
- Transpose, then reverse each **column**.
- Or reverse each row first, then transpose.
- Same `O(n^2)` time and `O(1)` space.

### Q2. How do you rotate 180 degrees?

**Answer:**
- Reverse the order of the rows.
- Then reverse each row.
- Or turn 90 degrees twice (more work).

### Q3. Is there another in-place way?

**Answer:**
- Yes: **layer by layer**. For each ring, move 4 cells at a time: left to top, bottom to left, right to bottom, top to right.
- Also `O(n^2)` time and `O(1)` space.
- It has more index math, so transpose + reverse is easier to get right.

### Q4. What if the matrix is m x n?

**Answer:**
- The answer is `n x m`. It does not fit in the same shape.
- Build a new matrix with `rotated[col][m - 1 - row] = matrix[row][col]`.

### Q5. How do you test it quickly?

**Answer:**
- Turn the matrix four times. It must be the original again.
- Compare with the simple extra-matrix version.

## 8. Interview Explanation

> A clockwise turn sends the cell at (row, col) to (col, n - 1 - row). Moving cells directly would overwrite others, so I split the turn into two mirror flips that are only swaps. First I transpose, swapping matrix[row][col] with matrix[col][row] for col greater than row, which sends (row, col) to (col, row). Then I reverse each row, which sends (col, row) to (col, n - 1 - row). That is O(n^2) time and O(1) extra space.
