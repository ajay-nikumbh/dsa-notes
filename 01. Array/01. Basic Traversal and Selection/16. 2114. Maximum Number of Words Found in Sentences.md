# 16. 2114. Maximum Number of Words Found in Sentences

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Basic Traversal and Selection | [2114. Maximum Number of Words Found in Sentences](https://leetcode.com/problems/maximum-number-of-words-found-in-sentences/) | `O(L)` | `O(1)` |

`L` = total number of characters in all sentences.

## 1. Problem Statement

A **sentence** is a list of words with exactly one space between words. There are no spaces at the start or the end.

You get an array of strings `sentences`. Each string is one sentence.

Return the **largest number of words** in any single sentence.

### Example

```text
sentences = ["alice and bob love leetcode",
             "i think so too",
             "this is great thanks very much"]

Sentence 0: alice | and | bob | love | leetcode        -> 5 words
Sentence 1: i | think | so | too                       -> 4 words
Sentence 2: this | is | great | thanks | very | much   -> 6 words

Output: 6
```

We use this same example in every section below.

### Constraints

- `1 <= sentences.length <= 100`
- `1 <= sentences[i].length <= 100`
- `sentences[i]` has only lowercase English letters and `' '`
- No leading or trailing spaces
- Words are separated by exactly one space

## 2. Core Theory

### What the problem really asks

Count the words in each sentence, then keep the biggest count. This is "traverse and select the maximum".

### The key observation

Spaces sit **between** words. With exactly one space between each pair:

```text
"i think so too"
  ^     ^  ^
  3 spaces  ->  4 words

words = spaces + 1
```

It is like fence posts: 4 posts need 3 gaps.

So we do not need to cut the sentence into words. Counting spaces is enough.

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| One word sentence | `["hello"]` | `1` | 0 spaces still means 1 word. Do not forget the `+ 1` |
| One sentence only | `["a b c"]` | `3` | The max is that sentence |
| Tie | `["a b", "c d"]` | `2` | Ties do not change the answer |
| Longest is first | `["a b c", "d"]` | `3` | Max must be kept, not overwritten by later smaller counts |

## 4. Brute Force: Split Into Words

### Idea

For each sentence, call `split(" ")` to get the list of words. Its length is the word count. Keep the max.

### Code

```python
# Import List for type hints
from typing import List


# Count words by splitting each sentence
class SolutionBrute:

    # Main method
    def mostWordsFound(self, sentences: List[str]) -> int:

        # Best count so far
        best = 0

        # Go through every sentence
        for s in sentences:

            # Cut the sentence into a list of words
            words = s.split(" ")

            # Keep the bigger count
            best = max(best, len(words))

        # Return the best count
        return best
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(L)` | Every character is read once by `split` |
| **Space** | `O(m)` | The word list for one sentence, `m` = longest sentence length |

## 5. Optimal Approach: Count Spaces

### Idea

1. `best = 0`.
2. For each sentence `s`, `words = s.count(" ") + 1`.
3. `best = max(best, words)`.
4. Return `best`.

Same time, but no new list of words is made.

### Visual Walkthrough (Story Version)

**The story:** three trains are in a station. Each word is a train car. Cars are hooked together with one link each (the spaces). We want the **longest train**. A smart worker does not count cars. He counts links, then adds one.

**How to read the pictures:** `[word]` is a car. `-` is a link. The best train so far is written on the right.

**Start**

```text
best = 0
```

**Train 1: `"alice and bob love leetcode"`**

```text
[alice]-[and]-[bob]-[love]-[leetcode]
       1     2     3      4

links = 4, cars = 4 + 1 = 5
5 > 0, so best = 5
```

**Train 2: `"i think so too"`**

```text
[i]-[think]-[so]-[too]
   1       2    3

links = 3, cars = 3 + 1 = 4
4 > 5? No. best stays 5
```

**Train 3: `"this is great thanks very much"`**

```text
[this]-[is]-[great]-[thanks]-[very]-[much]
      1    2       3        4      5

links = 5, cars = 5 + 1 = 6
6 > 5, so best = 6
```

The longest train has 6 cars.

**All trains at a glance**

| Train | Links | Cars | Best after |
|:---:|:---:|:---:|:---:|
| start | – | – | 0 |
| 1 | 4 | 5 | 5 |
| 2 | 3 | 4 | 5 |
| 3 | 5 | 6 | 6 |

**What the story teaches**

| In the story | In the code |
|:---|:---|
| Train | Sentence `s` |
| Car | Word |
| Link | Space `" "` |
| Cars = links + 1 | `s.count(" ") + 1` |
| Longest train so far | `best` |

### Step-by-Step Example

```text
sentences = ["alice and bob love leetcode",
             "i think so too",
             "this is great thanks very much"]
best = 0
```

**Step 1: `s = "alice and bob love leetcode"`**

1. Spaces are after `alice`, `and`, `bob`, `love`. `s.count(" ") = 4`.
2. `words = 4 + 1 = 5`.
3. `best = max(0, 5) = 5`.

```text
best = 5
```

**Step 2: `s = "i think so too"`**

1. Spaces are after `i`, `think`, `so`. `s.count(" ") = 3`.
2. `words = 3 + 1 = 4`.
3. `best = max(5, 4) = 5`.

```text
best = 5
```

**Step 3: `s = "this is great thanks very much"`**

1. Spaces are after `this`, `is`, `great`, `thanks`, `very`. `s.count(" ") = 5`.
2. `words = 5 + 1 = 6`.
3. `best = max(5, 6) = 6`.

```text
best = 6
```

The loop ends. **Answer: `6`.**

### Code

```python
# Import List for type hints
from typing import List


# Solution for 2114. Maximum Number of Words Found in Sentences
class Solution:

    # Main method
    def mostWordsFound(self, sentences: List[str]) -> int:

        # Best count so far
        best = 0

        # Go through every sentence
        for s in sentences:

            # Words are one more than spaces
            words = s.count(" ") + 1

            # Keep the bigger count
            best = max(best, words)

        # Return the best count
        return best


# The example sentences
```

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(L)` | `count` reads every character once |

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Returning the space count | Off by one: `"hello"` gives `0` | Add `1` |
| Returning the longest sentence string | Problem asks for the word count | Return a number |
| Counting characters instead of words | `len(s)` gives letters plus spaces | Count spaces, then add `1` |
| Counting spaces when there could be double spaces | Wrong count in general text | Here the problem promises single spaces. In real text, use `len(s.split())` |

## 7. Interview Follow-ups

### Q1. Why is words = spaces + 1 correct here?

**Answer:**
- Each space sits between two words.
- No spaces at the start or end, and no double spaces.
- So `n` words always have `n - 1` spaces.

### Q2. What if there could be extra spaces?

**Answer:**
- Use `len(s.split())`. With no argument, `split` ignores runs of spaces and spaces at the ends.
- Or count positions where a letter starts after a space (or at the start).

### Q3. What if they want the sentence itself, not the count?

**Answer:**
- Keep `best_index` next to `best`.
- Update both when you see a bigger count.

### Q4. Can you write it in one line?

**Answer:**
- `return max(s.count(" ") for s in sentences) + 1`.
- Same idea: the biggest space count, plus one.

## 8. Interview Explanation

> I need the biggest word count among all sentences. Since words are separated by exactly one space with nothing at the ends, every sentence has one more word than spaces. So for each sentence I count spaces, add one, and keep the max. That reads each character once, O(L) total, and uses O(1) extra space because I never build a list of words.
