# 18. 2574. Left and Right Sum Differences

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Basic Traversal and Selection | [2574. Left and Right Sum Differences](https://leetcode.com/problems/left-and-right-sum-differences/) | `O(n)` | `O(1)` extra |

## 1. Problem Statement

You get an integer array `nums` of length `n`.

For each index `i`:

- `leftSum[i]` = sum of everything **left** of `i` (`0` if nothing is there).
- `rightSum[i]` = sum of everything **right** of `i` (`0` if nothing is there).

Return an array `answer` where `answer[i] = |leftSum[i] - rightSum[i]|`.

### Example

```text
nums = [10, 4, 8, 3]

index:     0    1    2    3
nums:     10    4    8    3
leftSum:   0   10   14   22
rightSum: 15   11    3    0
|diff|:   15    1   11   22

Output: [15, 1, 11, 22]
```

We use this same example in every section below.

### Constraints

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^5`

## 2. Core Theory

### What the problem really asks

At every position, compare "everything before me" with "everything after me".

### The key observation

The whole array is made of three parts:

```text
[ left part ][ nums[i] ][ right part ]
  leftSum      current    rightSum

total = leftSum + nums[i] + rightSum
so:
rightSum = total - leftSum - nums[i]
```

- `leftSum` is easy to keep while walking left to right: just add each number after you use it.
- `rightSum` then comes for free from `total`.

So we need one pass to get `total`, and one pass to build the answer.

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| One element | `[1]` | `[0]` | Both sides are empty, so both sums are `0` |
| Two elements | `[3, 5]` | `[5, 3]` | First index has empty left, last has empty right |
| All same | `[2, 2, 2]` | `[4, 0, 4]` | Middle is balanced |
| Big values | `1000` values of `10^5` | Works | Sums reach `10^8`, fine in Python (and in a 32-bit int) |

## 4. Brute Force: Sum Both Sides Every Time

### Idea

For each `i`, add up `nums[0..i-1]` and `nums[i+1..n-1]` from scratch.

### Code

```python
# Import List for type hints
from typing import List


# Recompute both sums at every index
class SolutionBrute:

    # Main method
    def leftRightDifference(self, nums: List[int]) -> List[int]:

        # Number of elements
        n = len(nums)

        # The answer list
        answer = []

        # Go through every index
        for i in range(n):

            # Sum of everything left of i
            left = sum(nums[:i])

            # Sum of everything right of i
            right = sum(nums[i + 1:])

            # Store the absolute difference
            answer.append(abs(left - right))

        # Return the answer
        return answer
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n²)` | Each index sums up to `n` numbers |
| **Space** | `O(n)` | Slices make copies, plus the answer |

## 5. Better Approach: Prefix and Suffix Arrays

### Idea

Build `leftSum` in one pass from the left. Build `rightSum` in one pass from the right. Then subtract.

### Code

```python
# Import List for type hints
from typing import List


# Use two helper arrays
class SolutionBetter:

    # Main method
    def leftRightDifference(self, nums: List[int]) -> List[int]:

        # Number of elements
        n = len(nums)

        # Left sums, all start at 0
        left = [0] * n

        # Right sums, all start at 0
        right = [0] * n

        # Fill left sums from index 1
        for i in range(1, n):

            # Left of i = left of i-1 plus nums[i-1]
            left[i] = left[i - 1] + nums[i - 1]

        # Fill right sums from the second last index down
        for i in range(n - 2, -1, -1):

            # Right of i = right of i+1 plus nums[i+1]
            right[i] = right[i + 1] + nums[i + 1]

        # Build the answer from both arrays
        return [abs(left[i] - right[i]) for i in range(n)]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Three simple passes |
| **Space** | `O(n)` | Two helper arrays |

## 6. Optimal Approach: Total Minus Running Left

### Idea

1. `total = sum(nums)`.
2. `left = 0`.
3. For each `i`: `right = total - left - nums[i]`, store `|left - right|`, then `left += nums[i]`.

No helper arrays. Only two numbers.

### Visual Walkthrough (Story Version)

**The story:** 4 bags of coins sit on a table: `10`, `4`, `8`, `3`. A kid walks along the table. At each bag, she stops and asks: "How many coins are **behind** me, and how many are **in front** of me?"

She knows the **total** is `25`. She keeps a basket of coins she has walked past. So:

`in front = total - basket - this bag`

**How to read the pictures:** `[x]` is a bag. `^` is where the kid stands. `basket` is the sum behind her.

**Step 2: `i = 1`, `nums[1] = 4`**

1. `right = 25 - 10 - 4 = 11`.
2. `|10 - 11| = 1`. `answer = [15, 1]`.
3. `left = 10 + 4 = 14`.

**Step 3: `i = 2`, `nums[2] = 8`**

1. `right = 25 - 14 - 8 = 3`.
2. `|14 - 3| = 11`. `answer = [15, 1, 11]`.
3. `left = 14 + 8 = 22`.

**Step 4: `i = 3`, `nums[3] = 3`**

1. `right = 25 - 22 - 3 = 0`.
2. `|22 - 0| = 22`. `answer = [15, 1, 11, 22]`.
3. `left = 22 + 3 = 25`.

```text
answer = [15, 1, 11, 22]
left   = 25 (equals total, as it should)
```

**Answer: `[15, 1, 11, 22]`.**

### Code

```python
# Import List for type hints
from typing import List


# Solution for 2574. Left and Right Sum Differences
class Solution:

    # Main method
    def leftRightDifference(self, nums: List[int]) -> List[int]:

        # Sum of the whole array
        total = sum(nums)

        # Sum of everything left of the current index
        left = 0

        # The answer list
        answer = []

        # Go through every value
        for x in nums:

            # Everything right of here
            right = total - left - x

            # Store the absolute difference
            answer.append(abs(left - right))

            # Move this value into the left side
            left += x

        # Return the answer
        return answer
```

| Measure | Complexity | Why |
|:---|:---:|:---|

## 7. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Adding `nums[i]` to `left` **before** computing `right` | The current value is counted on the left side | Compute `right` and the diff first, then `left += x` |
| `right = total - left` | Forgets to remove the current value | `right = total - left - x` |
| Forgetting `abs` | Negative answers | Use `abs(left - right)` |
| Including `nums[i]` in a side | Problem says strictly left and strictly right | Exclude the current element from both |

## 8. Interview Follow-ups

### Q1. Why does `right = total - left - x` work?

**Answer:**
- The array is left part, current value, right part.
- They add up to `total`.
- So the right part is what is left after removing the other two.

### Q2. Where else is this trick used?

**Answer:**
- LeetCode 724, Find Pivot Index: find `i` where `left == right`.
- LeetCode 1991, Find the Middle Index: same idea.
- Any problem that needs "sum before" and "sum after" in one pass.

### Q3. What if the array is huge and numbers are big in Java or C++?

**Answer:**
- Here the max sum is `1000 * 10^5 = 10^8`, which fits in a 32-bit int.
- For bigger inputs, use `long`.

### Q4. Can we skip the first pass for `total`?

**Answer:**
- Not without helper arrays. We must know the total to get the right side.
- Two `O(n)` passes are still `O(n)`.

### Q5. What if we wanted products instead of sums?

**Answer:**
- That is LeetCode 238, Product of Array Except Self.
- Division is not allowed there, so we use a left pass and a right pass of running products.

## 9. Interview Explanation

> For every index I need the sum before it and the sum after it. Recomputing both each time is O(n²), and prefix and suffix arrays fix that with O(n) space. I can do better: first take the total, then walk left to right keeping a running left sum. The right sum is just total minus left minus the current value. I store the absolute difference, then add the current value to left. That is two passes, O(n) time and O(1) extra space.
