# 26. 3146. Permutation Difference between Two Strings

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Traversal: Index Lookup Table | [3146. Permutation Difference between Two Strings](https://leetcode.com/problems/permutation-difference-between-two-strings/) | `O(n)` | `O(1)` |

## 1. Problem Statement

You get two strings `s` and `t`.

- Every character appears **at most once** in `s`.
- `t` is a **permutation** of `s` (same letters, maybe a different order).

The **permutation difference** is the sum, over every character, of:

```text
| index of that character in s  -  index of that character in t |
```

Return the permutation difference.

### Example

```text
s = "abc"
t = "bac"

index:  0 1 2
s:      a b c
t:      b a c

'a': in s at 0, in t at 1  -> |0 - 1| = 1
'b': in s at 1, in t at 0  -> |1 - 0| = 1
'c': in s at 2, in t at 2  -> |2 - 2| = 0

Output: 1 + 1 + 0 = 2
```

We use this same example in every section below.

### Constraints

- `1 <= s.length <= 26`
- Each character occurs at most once in `s`
- `t` is a permutation of `s`
- `s` has only lowercase English letters

## 2. Core Theory

### What the problem really asks

For each letter, we need two numbers: where it sits in `s`, and where it sits in `t`. Then we add up how far it moved.

The slow part is **finding** a letter. `t.index(c)` scans the string every time.

### Why a lookup table fits

- Letters in `s` are unique, so each letter has exactly one index.
- Save `letter -> index in s` in a dictionary once.
- Then walk `t`. At position `j` we already know the index in `t` (it is `j`), and the dictionary gives the index in `s` in `O(1)`.

```text
Lookup table from s = "abc":

   'a' -> 0
   'b' -> 1
   'c' -> 2

Walk t = "bac":
   j=0 'b' -> table says 1 -> |1 - 0| = 1
   j=1 'a' -> table says 0 -> |0 - 1| = 1
   j=2 'c' -> table says 2 -> |2 - 2| = 0
```

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| Single letter | `s = "a", t = "a"` | `0` | Nothing can move |
| Same order | `s = "abc", t = "abc"` | `0` | Every distance is 0 |
| Fully reversed | `s = "abcd", t = "dcba"` | `8` | `3 + 1 + 1 + 3`. Biggest moves |
| LeetCode example 2 | `s = "abcde", t = "edbac"` | `12` | Longer check with mixed moves |
| All 26 letters reversed | `s = "a..z", t = "z..a"` | `338` | Largest input size |

## 4. Brute Force: Search Each Letter in t

### Idea

For each index `i` in `s`, find the same letter in `t` with `t.index(...)`. Add the distance.

### Code

```python
# Search for each letter of s inside t
class SolutionBrute:

    # Main method
    def findPermutationDifference(self, s: str, t: str) -> int:

        # Running sum of distances
        total = 0

        # Go through every index of s
        for i in range(len(s)):

            # Scan t to find where this letter sits
            j = t.index(s[i])

            # Add how far the letter moved
            total += abs(i - j)

        # Return the sum
        return total
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | `t.index` is `O(n)` and runs `n` times |
| **Space** | `O(1)` | Only a few variables |

Since `n <= 26`, this also passes. But the lookup table is the clean idea to show.

## 5. Optimal Approach: Lookup Table of Positions

### Idea

1. Build `pos`: for every letter in `s`, store its index.
2. Walk `t` with index `j`.
3. Add `abs(pos[t[j]] - j)` to the total.
4. Return the total.

### Visual Walkthrough (Story Version)

**The story:** three kids, `a`, `b` and `c`, sit in chairs 0, 1 and 2 for a class photo. After lunch they come back and sit in a new order. The teacher wants to know: **how many chairs did the kids move in total?**

First the teacher writes down the morning seats in a notebook. Then she walks along the afternoon row and, for each kid, checks the notebook.

**How to read the pictures:** the top row is the morning (`s`), the bottom row is the afternoon (`t`). `^` is the chair the teacher is looking at.

**Start: teacher writes the notebook from the morning row**

```text

Notebook: a -> 0, b -> 1, c -> 2
Total moved: 0
```

**Step 1: afternoon chair 0 has kid `b`**

```text

                 ^
Notebook says b was in chair 1. Now in chair 0.
Moved |1 - 0| = 1.        Total moved: 1
```

**Step 2: afternoon chair 1 has kid `a`**

```text
Afternoon (t):  [b][a][c]
                    ^
Notebook says a was in chair 0. Now in chair 1.

```

**Step 3: afternoon chair 2 has kid `c`**

```text
Afternoon (t):  [b][a][c]
                       ^
Notebook says c was in chair 2. Still in chair 2.
```

**End:** the kids moved 2 chairs in total.

### Step-by-Step Example

```text
s = "abc", t = "bac"
```

**Build the table from `s`**

| i | `s[i]` | `pos` after this step |
|:---:|:---:|:---|
| 0 | `a` | `{a: 0}` |
| 1 | `b` | `{a: 0, b: 1}` |
| 2 | `c` | `{a: 0, b: 1, c: 2}` |

**Start the walk on `t`:** `total = 0`

**Step 1: `j = 0`, `t[0] = 'b'`**

1. `pos['b'] = 1`.
2. Distance `= |1 - 0| = 1`.
3. `total = 0 + 1 = 1`.

**Step 2: `j = 1`, `t[1] = 'a'`**

1. `pos['a'] = 0`.
2. Distance `= |0 - 1| = 1`.
3. `total = 1 + 1 = 2`.

**Step 3: `j = 2`, `t[2] = 'c'`**

1. `pos['c'] = 2`.
2. Distance `= |2 - 2| = 0`.
3. `total = 2 + 0 = 2`.

**End:** return `total = 2`.

### Code

```python
# Use a table of positions to avoid searching
class Solution:

    # Main method
    def findPermutationDifference(self, s: str, t: str) -> int:

        # Empty table: letter -> index in s
        pos = {}

        # Fill the table from s
        for i, ch in enumerate(s):

            # Remember where this letter sits in s
            pos[ch] = i

        # Running sum of distances
        total = 0

        # Walk t; j is the index in t
        for j, ch in enumerate(t):

            # Add how far this letter moved
            total += abs(pos[ch] - j)

        # Return the sum
        return total


# The example from this note
s, t = "abc", "bac"

# Replay the table-building steps
pos = {}

# Expected table after each letter of s
expected_tables = [{"a": 0}, {"a": 0, "b": 1}, {"a": 0, "b": 1, "c": 2}]

# Check each table step
for i, ch in enumerate(s):

    # Add this letter
    pos[ch] = i

    # Table must match the trace
    assert pos == expected_tables[i]

# Replay the walk over t
total = 0

# Expected total after each step
expected_totals = [1, 2, 2]

# Check each walk step
for j, ch in enumerate(t):

    # Add this letter's distance
    total += abs(pos[ch] - j)

    # Total must match the trace
    assert total == expected_totals[j]

# Full example
assert Solution().findPermutationDifference("abc", "bac") == 2

# LeetCode example 2
assert Solution().findPermutationDifference("abcde", "edbac") == 12

# Edge case: single letter
assert Solution().findPermutationDifference("a", "a") == 0

# Edge case: same order
assert Solution().findPermutationDifference("abc", "abc") == 0

# Edge case: fully reversed
assert Solution().findPermutationDifference("abcd", "dcba") == 8

# Edge case: all 26 letters reversed
letters = "abcdefghijklmnopqrstuvwxyz"

# Sum of |i - (25 - i)| for i in 0..25 is 338
assert Solution().findPermutationDifference(letters, letters[::-1]) == 338

# Brute force gives the same answers
for a, b in [("abc", "bac"), ("abcde", "edbac"), ("a", "a"), ("abcd", "dcba"), (letters, letters[::-1])]:

    # Both methods must agree
    assert SolutionBrute().findPermutationDifference(a, b) == Solution().findPermutationDifference(a, b)

# All checks passed
print("All tests passed")
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | One pass to build the table, one pass over `t` |
| **Space** | `O(1)` | At most 26 entries in the table |

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Forgetting `abs` | Negative distances cancel out, sum can become 0 | Always use `abs(pos[ch] - j)` |
| Comparing `s[i]` with `t[i]` | That checks if letters match, not how far they moved | Look up the letter's index in the other string |
| Building the table from `t` and walking `t` | Every distance becomes 0 | Table from one string, walk the other |
| Calling `t.index` in a loop on long strings | Hidden `O(n^2)` | Use a dictionary or a 26-slot array |

## 7. Interview Follow-ups

### Q1. Can you use an array instead of a dictionary?

**Answer:**
- Yes. Use `pos = [0] * 26`.
- Store `pos[ord(ch) - ord('a')] = i`.
- Same `O(n)` time, and still `O(1)` space.

### Q2. What if letters can repeat in `s`?

**Answer:**
- Then "the index of a letter" is not one number.
- A common rule is to match the k-th copy in `s` with the k-th copy in `t`.
- Store a list of indices per letter and pop them in order.

### Q3. Does it matter which string we build the table from?

**Answer:**
- No. `|a - b| == |b - a|`.
- Build from either one and walk the other.

### Q4. What is the largest possible answer?

**Answer:**
- When `t` is `s` reversed.
- For 26 letters that sum is `338`.

## 8. Interview Explanation

> For each letter I need its index in s and its index in t. Searching t for each letter would cost O(n) per letter, so instead I build a dictionary from letter to its index in s in one pass. Then I walk t with its index j and add the absolute difference between pos[letter] and j. The letters are unique, so each letter has one index. This is O(n) time and O(1) extra space, because there are at most 26 letters.
