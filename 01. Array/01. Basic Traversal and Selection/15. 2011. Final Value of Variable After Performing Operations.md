# 15. 2011. Final Value of Variable After Performing Operations

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Basic Traversal and Selection | [2011. Final Value of Variable After Performing Operations](https://leetcode.com/problems/final-value-of-variable-after-performing-operations/) | `O(n)` | `O(1)` |

## 1. Problem Statement

There is a made-up language with one variable `X` and four operations:

- `++X` and `X++` add `1` to `X`.
- `--X` and `X--` subtract `1` from `X`.

`X` starts at `0`. You get a list of strings `operations`. Run them in order and return the final value of `X`.

### Example

```text
operations = ["--X", "X++", "X++"]

Start:      X = 0
"--X"   ->  X = -1
"X++"   ->  X = 0
"X++"   ->  X = 1

Output: 1
```

We use this same example in every section below.

### Constraints

- `1 <= operations.length <= 100`
- `operations[i]` is one of `"++X"`, `"X++"`, `"--X"`, `"X--"`

## 2. Core Theory

### What the problem really asks

Keep a running total. Add `1` or subtract `1` for each string.

### The key observation

Look at the **middle character** of each string:

```text
 "++X"   "X++"   "--X"   "X--"
   ^       ^       ^       ^
   +       +       -       -
```

- Every string has exactly 3 characters.
- The middle one (index `1`) is always `+` for an add, and `-` for a subtract.
- So we never need to compare the full string. One character tells us everything.

Pre or post (`++X` vs `X++`) does not matter here. Nothing reads `X` in between.

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| One operation | `["X++"]` | `1` | Smallest input |
| All minus | `["--X", "X--"]` | `-2` | Answer can be negative |
| Cancels out | `["X++", "--X"]` | `0` | Ups and downs cancel |
| All four forms | `["++X", "X++", "--X", "X--"]` | `0` | Pre and post forms both count |

## 4. Brute Force: Compare Full Strings

### Idea

For each string, check if it equals `"++X"` or `"X++"`. If yes, add `1`. Otherwise subtract `1`.

### Code

```python
# Import List for type hints
from typing import List


# Compare each operation with the full strings
class SolutionBrute:

    # Main method
    def finalValueAfterOperations(self, operations: List[str]) -> int:

        # X starts at zero
        x = 0

        # Go through every operation
        for op in operations:

            # Is it one of the two add forms?
            if op == "++X" or op == "X++":

                # Add one
                x += 1

            # Otherwise it is a subtract form
            else:

                # Subtract one
                x -= 1

        # Return the final value
        return x
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | One check per operation (each string has 3 characters) |
| **Space** | `O(1)` | Only `x` |

## 5. Optimal Approach: Check the Middle Character

### Idea

1. Start `x = 0`.
2. For each `op`, if `op[1] == "+"`, add `1`. Otherwise subtract `1`.
3. Return `x`.

Same `O(n)`, but each check is one character instead of a full string compare.

### Visual Walkthrough (Story Version)

**The story:** a kid stands on a staircase at step `0`. A teacher hands out three cards. Each card has an arrow in the middle. `+` means **walk up one step**. `-` means **walk down one step**. Where does the kid end up?

**How to read the pictures:** `*` is the kid. The number line is the staircase.

**Start**

```text

             *
```

**Card 1: `"--X"`**

- Middle is `-`. Walk down one step.

```text

        *
```

**Card 2: `"X++"`**

- Middle is `+`. Walk up one step.

```text
step:  -1   0   1
             *
```

**Card 3: `"X++"`**

- Middle is `+`. Walk up one step.

```text

```

The kid is on step `1`.

**All cards at a glance**

| Card | String | Middle | Move | Step after |
|:---:|:---:|:---:|:---:|:---:|
| start | – | – | – | 0 |
| 1 | `"--X"` | `-` | down | -1 |

| In the story | In the code |
|:---|:---|
| Kid's step | `x` |
| Card | `op` |
| Middle arrow | `op[1]` |
| Walk up / down | `x += 1` / `x -= 1` |

### Step-by-Step Example

```text
operations = ["--X", "X++", "X++"]
x = 0
```

**Step 1: `op = "--X"`**

1. `op[1] = "-"`.
2. `"-" == "+"` is `False`.
3. `x = 0 - 1 = -1`.

```text
x = -1
```

**Step 2: `op = "X++"`**

1. `op[1] = "+"`.
2. `"+" == "+"` is `True`.
3. `x = -1 + 1 = 0`.

```text
x = 0
```

**Step 3: `op = "X++"`**

1. `op[1] = "+"`.
2. `"+" == "+"` is `True`.
3. `x = 0 + 1 = 1`.

```text
x = 1
```

The loop ends. **Answer: `1`.**

### Code

```python
# Import List for type hints
from typing import List


# Solution for 2011. Final Value of Variable After Performing Operations
class Solution:

    # Main method
    def finalValueAfterOperations(self, operations: List[str]) -> int:

        # X starts at zero
        x = 0

        # Go through every operation
        for op in operations:

            # The middle character tells add or subtract
            if op[1] == "+":

                # Add one
                x += 1

            # Middle is a minus
            else:

                # Subtract one
                x -= 1

        # Return the final value
        return x


# Trace the example by hand
x = 0

# Step 1: "--X" has a minus in the middle
x += 1 if "--X"[1] == "+" else -1

# Check after step 1
assert x == -1

# Step 2: "X++" has a plus in the middle
x += 1 if "X++"[1] == "+" else -1

# Check after step 2
assert x == 0

# Step 3: "X++" has a plus in the middle
x += 1 if "X++"[1] == "+" else -1

# Check after step 3
assert x == 1

# Full solution on the example
assert Solution().finalValueAfterOperations(["--X", "X++", "X++"]) == 1

# LeetCode example 2
assert Solution().finalValueAfterOperations(["++X", "++X", "X++"]) == 3

# LeetCode example 3
assert Solution().finalValueAfterOperations(["X++", "++X", "--X", "X--"]) == 0

# One operation
assert Solution().finalValueAfterOperations(["X++"]) == 1

# All minus
assert Solution().finalValueAfterOperations(["--X", "X--"]) == -2

# Import random for brute force comparison
import random

# Try many random lists
for _ in range(200):

    # Make a random list of operations
    ops = [random.choice(["++X", "X++", "--X", "X--"]) for _ in range(random.randint(1, 100))]

    # Brute force and optimal must agree
    assert SolutionBrute().finalValueAfterOperations(ops) == Solution().finalValueAfterOperations(ops)

# All checks passed
print("All tests passed")
```

| Measure | Complexity | Why |

| **Space** | `O(1)` | Only `x` |

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Checking only `op == "X++"` | `"++X"` is counted as a minus | Check the middle character, or both add forms |
| Checking `op[0] == "+"` | `"X++"` starts with `X`, so it is counted as a minus | Use `op[1]`, which is the same for both forms |
| Thinking pre and post give different results | Overthinking | Nothing reads `X` in between, so both just add `1` |

## 7. Interview Follow-ups

### Q1. Why is the middle character always enough?

**Answer:**
- All four strings have length 3.
- In `"++X"` and `"X++"`, index `1` is `+`. In `"--X"` and `"X--"`, index `1` is `-`.
- So index `1` is `+` for add and `-` for subtract.

### Q2. Can you write it in one line?

**Answer:**
- `return sum(1 if op[1] == "+" else -1 for op in operations)`.
- Same `O(n)` time and `O(1)` space.

### Q3. What if there were also `X*=2` operations?

**Answer:**
- Then order matters a lot, and the middle-character trick breaks.
- Parse each string and apply it in order, like a tiny interpreter.

### Q4. What if there were many variables, like `Y++`?

**Answer:**
- Keep a dictionary from variable name to value.
- Find the name by removing the `++` or `--` part.

## 8. Interview Explanation

> X starts at 0 and every operation either adds 1 or subtracts 1. All four strings have length 3 and the sign sits in the middle, so I only check op[1]: if it is "+", I add 1, otherwise I subtract 1. Pre and post forms do not matter because nothing reads X in between. That is one pass, O(n) time and O(1) space.
