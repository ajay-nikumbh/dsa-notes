# 27. 414. Third Maximum Number

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Traversal: Top-3 Trackers | [414. Third Maximum Number](https://leetcode.com/problems/third-maximum-number/) | `O(n)` | `O(1)` |

## 1. Problem Statement

You get an integer array `nums`.

Return the **third distinct maximum** number in the array.

If there is no third distinct maximum (fewer than 3 different values), return the **maximum** number.

### Example

```text
nums = [2, 2, 3, 1]

Different values, biggest first: 3, 2, 1
  1st distinct max = 3
  2nd distinct max = 2   (the two 2s count only once)
  3rd distinct max = 1

Output: 1
```

We use this same example in every section below.

### Constraints

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- Follow-up: can you do it in `O(n)`?

## 2. Core Theory

### What the problem really asks

"Distinct" is the key word. Equal values count as **one** value.

So `[2, 2, 3, 1]` has only three different values: `3, 2, 1`. The third one is `1`.

### Why three trackers fit

This is the same idea as "second largest", with one more slot.

Keep three boxes: `first >= second >= third`, all different.

When a new number `x` comes:

```text
x already in a box?      -> ignore it (it is a duplicate)
x > first                -> everybody slides down one box, x goes in first
first > x > second       -> second slides to third, x goes in second
second > x > third       -> x goes in third
smaller than all three   -> ignore it
```

```text
Slide down when a new biggest arrives:

 before:  first=3   second=2   third=1
 x = 5:   first=5   second=3   third=2      (1 falls out)
```

We use `None` to mean "box is still empty". This is safer than using `-infinity` or `-2^31`, because `-2^31` is a real value that can appear in `nums`.

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| Fewer than 3 distinct | `[1, 2]` | `2` | No third max, so return the max |
| Duplicates hide the third | `[2, 2, 3, 1]` | `1` | The two 2s count once |
| All equal | `[5, 5, 5]` | `5` | Only one distinct value |
| Minimum int is the answer | `[1, 2, -2147483648]` | `-2147483648` | Breaks code that uses `-2^31` as "empty" |
| Single element | `[7]` | `7` | Smallest input |
| Negatives | `[-1, -2, -3, -4]` | `-3` | Order still works with negatives |

## 4. Brute Force: Remove Duplicates and Sort

### Idea

Turn the array into a set to drop duplicates. Sort it from big to small. If there are at least 3 values, return the third one. Else return the first one.

### Code

```python
# Import List for type hints
from typing import List


# Remove duplicates, sort, and pick
class SolutionBrute:

    # Main method
    def thirdMax(self, nums: List[int]) -> int:

        # Keep each value once, biggest first
        values = sorted(set(nums), reverse=True)

        # Enough distinct values: return the third
        if len(values) >= 3:
            return values[2]

        # Otherwise return the maximum
        return values[0]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n log n)` | Sorting the distinct values |
| **Space** | `O(n)` | The set and the sorted list |

## 5. Optimal Approach: Three Trackers in One Pass

### Idea

1. Start with `first = second = third = None`.
2. For each `x`, skip it if it equals any tracker.
3. Otherwise place it in the right box and slide the smaller boxes down.
4. At the end, return `third` if it is filled, else `first`.

### Visual Walkthrough (Story Version)

**The story:** a race has a podium with three steps: gold, silver and bronze. Runners finish one by one and show their score. A score can win **only one** medal. If a runner has the same score as a medal winner, nobody moves.

**How to read the pictures:** `[G]` gold, `[S]` silver, `[B]` bronze. `_` means the step is still empty. `^` is the runner we are looking at.

**Start: empty podium**

```text
runners: [2][2][3][1]

podium:  G=_  S=_  B=_
```

**Step 1: runner with score 2**

```text
runners: [2][2][3][1]
          ^
Gold is empty. 2 takes gold.

podium:  G=2  S=_  B=_
```

**Step 2: runner with score 2 again**

```text
runners: [2][2][3][1]
             ^
Score 2 already holds gold. Same score, no new medal.

podium:  G=2  S=_  B=_
```

**Step 3: runner with score 3**

```text
runners: [2][2][3][1]
                ^
3 beats gold (2). Gold steps down to silver, silver (empty) steps down to bronze.
3 takes gold.

podium:  G=3  S=2  B=_
```

**Step 4: runner with score 1**

```text
runners: [2][2][3][1]
                   ^
1 does not beat gold (3). 1 does not beat silver (2).
Bronze is empty, so 1 takes bronze.

podium:  G=3  S=2  B=1
```

**End:** bronze is filled. The bronze score is the answer: `1`.

**All steps at a glance**

| Step | Score | What happens | Gold | Silver | Bronze |
|:---:|:---:|:---|:---:|:---:|:---:|
| start | – | Empty podium | _ | _ | _ |
| 1 | 2 | Takes empty gold | 2 | _ | _ |
| 2 | 2 | Same as gold, ignored | 2 | _ | _ |
| 3 | 3 | Beats gold, others step down | 3 | 2 | _ |
| 4 | 1 | Takes empty bronze | 3 | 2 | 1 |

**What the story teaches**

| In the story | In the code |
|:---|:---|
| Runner's score | `x` |
| Gold, silver, bronze | `first`, `second`, `third` |
| Empty step | `None` |
| Same score as a medal | `x == first or x == second or x == third` |
| Stepping down | `third, second, first = second, first, x` |
| Bronze winner | The answer `third` |
| No bronze winner | Return `first` |

### Step-by-Step Example

```text
nums = [2, 2, 3, 1]
```

**Start:** `first = None, second = None, third = None`

**Step 1: `x = 2`**

1. Is `2` equal to `first`, `second` or `third`? All are `None`. No.
2. Is `first` `None`? Yes. So slide down and put `2` in `first`.
3. `third = None`, `second = None`, `first = 2`.

```text
first = 2, second = None, third = None
```

**Step 2: `x = 2`**

1. Is `2 == first`? Yes. Duplicate. Skip.

```text
first = 2, second = None, third = None
```

**Step 3: `x = 3`**

1. Is `3` equal to any tracker? `3 != 2`. No.
2. Is `3 > first (2)`? Yes. Slide down.
3. `third = second = None`, `second = first = 2`, `first = 3`.

```text
first = 3, second = 2, third = None
```

**Step 4: `x = 1`**

1. Is `1` equal to any tracker? `1 != 3`, `1 != 2`. No.
2. Is `1 > first (3)`? No.
3. Is `second` `None` or `1 > second (2)`? No.
4. Is `third` `None`? Yes. So `third = 1`.

```text
first = 3, second = 2, third = 1
```

**End:** `third = 1` is not `None`. Return `1`.

### Code

```python
# Import List for type hints
from typing import List


# Solution for 414. Third Maximum Number
class Solution:

    # Return the three biggest distinct values seen (None = empty)
    def _top_three(self, nums: List[int]):

        # All three boxes start empty
        first = second = third = None

        # Look at every number once
        for x in nums:

            # Skip a value that is already in a box
            if x == first or x == second or x == third:
                continue

            # New biggest value: everybody slides down
            if first is None or x > first:

                # Old second goes to third, old first goes to second
                third, second, first = second, first, x

            # Fits between first and second
            elif second is None or x > second:

                # Old second goes to third
                third, second = second, x

            # Fits between second and third
            elif third is None or x > third:

                # Only third changes
                third = x

        # Return the three boxes
        return first, second, third

    # Main method
    def thirdMax(self, nums: List[int]) -> int:

        # Get the three biggest distinct values
        first, second, third = self._top_three(nums)

        # No third distinct value: return the maximum
        if third is None:
            return first

        # Otherwise return the third maximum
        return third


# The example from this note
nums = [2, 2, 3, 1]

# Boxes after each traced step
expected = [(2, None, None), (2, None, None), (3, 2, None), (3, 2, 1)]

# Check every traced step on the prefix
for step in range(4):

    # Boxes after step + 1 numbers must match the trace
    assert Solution()._top_three(nums[:step + 1]) == expected[step]

# Full example
assert Solution().thirdMax(nums) == 1

# LeetCode example 1
assert Solution().thirdMax([3, 2, 1]) == 1

# LeetCode example 2: fewer than 3 distinct
assert Solution().thirdMax([1, 2]) == 2

# Edge case: all equal
assert Solution().thirdMax([5, 5, 5]) == 5

# Edge case: minimum int is the answer
assert Solution().thirdMax([1, 2, -2147483648]) == -2147483648

# Edge case: single element
assert Solution().thirdMax([7]) == 7

# Edge case: negatives
assert Solution().thirdMax([-1, -2, -3, -4]) == -3

# Brute force gives the same answers
for arr in [nums, [3, 2, 1], [1, 2], [5, 5, 5], [1, 2, -2147483648], [7], [-1, -2, -3, -4], [1, 2, 2, 5, 3, 5]]:

    # Both methods must agree
    assert SolutionBrute().thirdMax(arr) == Solution().thirdMax(arr)

# All checks passed
print("All tests passed")
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | One pass, a few comparisons per number |
| **Space** | `O(1)` | Only three trackers |

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Not skipping duplicates | `[2, 2, 3, 1]` gives `2` instead of `1` | Skip `x` if it equals any tracker |
| Using `-2^31` or `float('-inf')` as "empty" with a value check | `[1, 2, -2147483648]` looks like it has no third max | Use `None` for empty |
| Using `>=` instead of `>` | Equal values slide into the next box | Skip equals first, then use strict `>` |
| Forgetting to slide down | Old first is lost when a bigger value comes | `third, second, first = second, first, x` |
| Returning `third` when it is empty | Returns `None` | Return `first` when `third is None` |

## 7. Interview Follow-ups

### Q1. How would you find the k-th distinct maximum?

**Answer:**
- Keep a min-heap of size `k` with distinct values, plus a set to know what is in it.
- Push new values; if the heap grows past `k`, pop the smallest.
- At the end the heap top is the k-th max. Time `O(n log k)`.

### Q2. Why not just use a set and sort?

**Answer:**
- It works but costs `O(n log n)` time and `O(n)` space.
- The follow-up asks for `O(n)`, which the trackers give with `O(1)` space.

### Q3. What if "distinct" was not required?

**Answer:**
- Then remove the duplicate check.
- Use `>=` so equal values can fill several boxes.
- `[2, 2, 3, 1]` would then return `2`.

### Q4. Why is `None` better than `-infinity` in Python?

**Answer:**
- With `float('-inf')` the comparisons work, but you still need a clear "is it filled?" test.
- In Java or C++ people use `Long.MIN_VALUE` for the same reason: `Integer.MIN_VALUE` is a real input.
- `None` makes "empty" impossible to confuse with a real number.

## 8. Interview Explanation

> I keep three trackers, first, second and third, for the three biggest distinct values, starting as None. For each number I skip it if it already equals a tracker, because duplicates count once. If it beats first, every tracker slides down one place; if it only beats second, second slides to third; if it only beats third, it replaces third. At the end I return third if it was filled, otherwise first. Using None for empty avoids bugs when the minimum integer is a real value. This is O(n) time and O(1) space.
