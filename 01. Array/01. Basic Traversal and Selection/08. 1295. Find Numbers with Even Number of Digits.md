# 08. 1295. Find Numbers with Even Number of Digits

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Basic Traversal and Selection | [1295. Find Numbers with Even Number of Digits](https://leetcode.com/problems/find-numbers-with-even-number-of-digits/) | `O(n · d)` | `O(1)` |

## 1. Problem Statement

You get an array `nums` of integers.

Return how many of them have an **even number of digits**.

### Example

```text
Input:  nums = [12, 345, 2, 6, 7896]
Output: 2

Why:
12   -> 2 digits (even)
345  -> 3 digits (odd)
2    -> 1 digit  (odd)
6    -> 1 digit  (odd)
7896 -> 4 digits (even)

Two numbers have an even digit count: 12 and 7896.
```

We use this same example in every section below.

### Constraints

- `1 <= nums.length <= 500`
- `1 <= nums[i] <= 10^5`

## 2. Core Theory

### What the problem really asks

For every number:

1. Count its digits.
2. If the count is even, add one to the answer.

This is a **count of matches** scan: walk once, test each element, count the ones that pass.

### How to count digits without strings

Divide by `10` until the number becomes `0`. Each division removes one digit.

```text
7896 -> 789 -> 78 -> 7 -> 0
  1      2     3    4         -> 4 digits
```

### Why `d` is tiny here

- `d` = number of digits = at most 6 (`100000` has 6).
- So the inner loop runs at most 6 times. The whole thing is basically `O(n)`.

### A shortcut for these limits

Since `1 <= nums[i] <= 10^5`, an even digit count means:

```text
10   <= num <= 99      (2 digits)
1000 <= num <= 9999    (4 digits)
100000                 (6 digits)
```

This range check is fast, but it only works for these limits. The digit loop works for any size.

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| All odd digit counts | `[1, 222, 33333]` | `0` | Counter must stay `0` |
| All even digit counts | `[10, 1000, 99]` | `3` | Every element is counted |
| Single digit | `[7]` | `0` | One digit is odd |
| Biggest value | `[100000]` | `1` | 6 digits, even |
| Powers of ten | `[10, 100]` | `1` | `10` has 2 digits, `100` has 3. Catches off-by-one in the loop |
| LeetCode example 2 | `[555, 901, 482, 1771]` | `1` | Only `1771` has 4 digits |

## 4. Brute Force: Convert to a String

### Idea

`len(str(num))` gives the digit count. Check if it is even.

### Code

```python
# Import List for type hints
from typing import List


# Brute force: turn each number into a string
class SolutionBrute:

    # Main method
    def findNumbers(self, nums: List[int]) -> int:

        # Numbers with an even digit count
        count = 0

        # Look at every number
        for num in nums:

            # The string length is the digit count
            digits = len(str(num))

            # Even digit count
            if digits % 2 == 0:

                # Count it
                count += 1

        # Return the total
        return count
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n · d)` | Building each string takes `d` steps |
| **Space** | `O(d)` | A temporary string for each number |

This is short and fine in practice. The optimal version avoids making strings and shows the math.

## 5. Optimal Approach: Count Digits by Dividing by 10

### Idea

1. `count = 0`.
2. For each `num`:
   - `digits = 0`.
   - While `num > 0`: `num //= 10`, `digits += 1`.
   - If `digits` is even, `count += 1`.
3. Return `count`.

### Visual Walkthrough (Story Version)

**The story:** five numbers are written on paper strips. A kid has scissors. For each strip, the kid **cuts off the last digit** again and again until nothing is left, counting the cuts. If the number of cuts is even, the strip goes into the **Even Box**.

**The rules:**

- One cut removes the last digit (`num // 10`).
- When the strip is empty (`0`), stop cutting.
- Even number of cuts -> Even Box gets one more strip.

**How to read the pictures:** `[ ]` = strips. `^` = the strip being cut. `Even Box` = the count so far.

**Start: no strip has been cut**

```text
[12][345][2][6][7896]

Even Box = 0
```

**Step 1: strip 12**

- Cut: 12 -> 1 (1 cut).
- Cut: 1 -> 0 (2 cuts). Empty, stop.
- 2 cuts is even. Strip goes in the box.

```text
[12][345][2][6][7896]
  ^
cuts = 2 (even)   Even Box = 1
```

**Step 2: strip 345**

- Cut: 345 -> 34 (1 cut).
- Cut: 34 -> 3 (2 cuts).
- Cut: 3 -> 0 (3 cuts). Empty, stop.
- 3 cuts is odd. Strip is thrown away.

```text
[12][345][2][6][7896]
      ^
cuts = 3 (odd)    Even Box = 1
```

**Step 3: strip 2**

- Cut: 2 -> 0 (1 cut). Empty, stop.
- 1 cut is odd. Thrown away.

```text
[12][345][2][6][7896]
          ^
cuts = 1 (odd)    Even Box = 1
```

**Step 4: strip 6**

- Cut: 6 -> 0 (1 cut). Empty, stop.
- 1 cut is odd. Thrown away.

```text
[12][345][2][6][7896]
             ^
cuts = 1 (odd)    Even Box = 1
```

**Step 5: strip 7896**

- Cut: 7896 -> 789 (1 cut).
- Cut: 789 -> 78 (2 cuts).
- Cut: 78 -> 7 (3 cuts).
- Cut: 7 -> 0 (4 cuts). Empty, stop.
- 4 cuts is even. Strip goes in the box.

```text
[12][345][2][6][7896]
                 ^
cuts = 4 (even)   Even Box = 2
```

**End:** the Even Box holds **2** strips. That is the answer.

**All steps at a glance**

| Step | Strip | Cuts (digits) | Even? | Even Box |
|:---:|:---:|:---:|:---:|:---:|
| start | – | – | – | 0 |
| 1 | 12 | 2 | Yes | 1 |
| 2 | 345 | 3 | No | 1 |
| 3 | 2 | 1 | No | 1 |
| 4 | 6 | 1 | No | 1 |
| 5 | 7896 | 4 | Yes | 2 |

**What the story teaches**

| In the story | In the code |
|:---|:---|
| Strip | `num` |
| One cut | `num //= 10` |
| Counting cuts | `digits += 1` |
| Strip is empty | `while num > 0` ends |
| Even number of cuts | `digits % 2 == 0` |
| Even Box | `count` |

### Step-by-Step Example

```text
nums = [12, 345, 2, 6, 7896]
count = 0
```

**Step 1: `num = 12`**

1. `digits = 0`.
2. `12 > 0`: `num = 12 // 10 = 1`, `digits = 1`.
3. `1 > 0`: `num = 1 // 10 = 0`, `digits = 2`.
4. `0 > 0`? No. Stop.
5. `2 % 2 == 0`? Yes. `count = 1`.

**Step 2: `num = 345`**

1. `digits = 0`.
2. `345 > 0`: `num = 34`, `digits = 1`.
3. `34 > 0`: `num = 3`, `digits = 2`.
4. `3 > 0`: `num = 0`, `digits = 3`.
5. `0 > 0`? No. Stop.
6. `3 % 2 == 0`? No. `count = 1`.

**Step 3: `num = 2`**

1. `digits = 0`.
2. `2 > 0`: `num = 0`, `digits = 1`.
3. `0 > 0`? No. Stop.
4. `1 % 2 == 0`? No. `count = 1`.

**Step 4: `num = 6`**

1. `digits = 0`.
2. `6 > 0`: `num = 0`, `digits = 1`.
3. `0 > 0`? No. Stop.
4. `1 % 2 == 0`? No. `count = 1`.

**Step 5: `num = 7896`**

1. `digits = 0`.
2. `7896 > 0`: `num = 789`, `digits = 1`.
3. `789 > 0`: `num = 78`, `digits = 2`.
4. `78 > 0`: `num = 7`, `digits = 3`.
5. `7 > 0`: `num = 0`, `digits = 4`.
6. `0 > 0`? No. Stop.
7. `4 % 2 == 0`? Yes. `count = 2`.

**Loop ends.** Return `count = 2`.

### Code

```python
# Import List for type hints
from typing import List


# Optimal: count digits with integer division
class Solution:

    # Main method
    def findNumbers(self, nums: List[int]) -> int:

        # Numbers with an even digit count
        count = 0

        # Look at every number
        for num in nums:

            # Digits counted for this number
            digits = 0

            # Keep cutting while digits remain
            while num > 0:

                # Remove the last digit
                num //= 10

                # One more digit counted
                digits += 1

            # Even digit count
            if digits % 2 == 0:

                # Count this number
                count += 1

        # Return the total
        return count


# Helper that returns the digit count of one number
def count_digits(num):

    # Digits counted
    digits = 0

    # Cut until nothing is left
    while num > 0:

        # Remove the last digit
        num //= 10

        # Count it
        digits += 1

    # Return the count
    return digits


# Helper that records (digits, count) after every step, to check the trace
def trace_even_digits(nums):

    # Running answer
    count = 0

    # States after each step
    states = []

    # Same loop as the solution
    for num in nums:

        # Digits of this number
        digits = count_digits(num)

        # Even digit count
        if digits % 2 == 0:

            # Count it
            count += 1

        # Save the state
        states.append((digits, count))

    # Return every state
    return states


# Example from this note
nums = [12, 345, 2, 6, 7896]

# Step 1 to Step 5
assert trace_even_digits(nums) == [(2, 1), (3, 1), (1, 1), (1, 1), (4, 2)]

# Final answer on the example (LeetCode example 1)
assert Solution().findNumbers(nums) == 2

# LeetCode example 2
assert Solution().findNumbers([555, 901, 482, 1771]) == 1

# Edge case: all odd digit counts
assert Solution().findNumbers([1, 222, 33333]) == 0

# Edge case: all even digit counts
assert Solution().findNumbers([10, 1000, 99]) == 3

# Edge case: single digit
assert Solution().findNumbers([7]) == 0

# Edge case: biggest value has 6 digits
assert Solution().findNumbers([100000]) == 1

# Edge case: powers of ten
assert Solution().findNumbers([10, 100]) == 1

# The input list must not be changed
assert nums == [12, 345, 2, 6, 7896]

# Brute force gives the same answers

    assert SolutionBrute().findNumbers(case) == Solution().findNumbers(case)

```

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| `while num >= 10` | Misses the last digit. `12` counts as 1 digit | Use `while num > 0` |
| `num /= 10` | Float division never reaches exactly `0` cleanly | Use `num //= 10` |
| Checking `num % 2 == 0` | Tests if the number is even, not its digit count | Test `digits % 2 == 0` |
| Not resetting `digits` for each number | Counts pile up across numbers | Set `digits = 0` inside the loop |
| Using `math.log10` without care | Float rounding can be off on exact powers of ten | Use the loop or `len(str(num))` |

## 7. Interview Follow-ups

### Q1. Can you count digits in `O(1)`?

**Answer:**
- Yes: `int(math.log10(num)) + 1` for `num > 0`.
- But float rounding can bite on big numbers. Be careful.
- For these limits, the range check `10..99`, `1000..9999`, `100000` also works.

### Q2. What if `nums` could contain `0` or negative numbers?

**Answer:**
- `0` has 1 digit, but the loop gives `0`. Handle `0` on its own.
- For negatives, use `abs(num)` first. The minus sign is not a digit.

### Q3. Which is faster in Python: string or division?

**Answer:**
- `len(str(num))` is often faster in Python because it runs in C.
- Division shows the logic and uses no extra memory.
- In an interview, mention both.

### Q4. What if numbers are huge (hundreds of digits)?

**Answer:**
- Division is `O(d^2)` for big integers in Python.
- `len(str(num))` is also costly. If numbers come as strings, just use the string length.

### Q5. Can you write it in one line?

**Answer:**
- `return sum(len(str(x)) % 2 == 0 for x in nums)`.
- `True` counts as `1` when summed.

## 8. Interview Explanation

> I walk the array once and count the numbers whose digit count is even. To count digits, I divide the number by 10 until it becomes 0, adding one each time. If the count is even, I add one to the answer. Each number has at most 6 digits here, so the inner loop is tiny. Total time is O(n · d), which is basically O(n), and space is O(1).
