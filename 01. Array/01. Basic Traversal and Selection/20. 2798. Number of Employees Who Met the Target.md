# 20. 2798. Number of Employees Who Met the Target

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Basic Traversal and Selection | [2798. Number of Employees Who Met the Target](https://leetcode.com/problems/number-of-employees-who-met-the-target/) | `O(n)` | `O(1)` |

## 1. Problem Statement

A company has `n` employees, numbered `0` to `n - 1`. Employee `i` worked `hours[i]` hours.

The company wants every employee to work **at least** `target` hours.

Return how many employees worked at least `target` hours.

### Example

```text
hours = [0, 1, 2, 3, 4], target = 2

employee:  0  1  2  3  4
hours:     0  1  2  3  4
>= 2 ?     no no yes yes yes

Output: 3
```

We use this same example in every section below.

### Constraints

- `1 <= n == hours.length <= 50`
- `0 <= hours[i], target <= 10^5`

## 2. Core Theory

### What the problem really asks

Count how many values pass a test: `hours[i] >= target`.

This is the most basic "traverse and count" pattern:

```text
count = 0
for each value:
    if value passes the test:
        count += 1
```

### Watch the word "at least"

"At least 2" means `2` is allowed. So the test is `>=`, not `>`.

```text
hours:  0   1   2   3   4
            target = 2
        no  no  YES YES YES
                ^
        equal still counts
```

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| Exactly equal | `[2], target = 2` | `1` | `>=` must include equal |
| Target is 0 | `[0, 0], target = 0` | `2` | Everyone meets it, even 0 hours |
| Nobody meets it | `[5, 1, 4, 2, 2], target = 6` | `0` | Count stays 0 |
| Everyone meets it | `[7, 8], target = 1` | `2` | Count equals `n` |

## 4. Brute Force: Collect Then Count

### Idea

Make a new list with only the employees who met the target. Return its length.

### Code

```python
# Import List for type hints
from typing import List


# Build a list of employees who met the target
class SolutionBrute:

    # Main method
    def numberOfEmployeesWhoMetTarget(self, hours: List[int], target: int) -> int:

        # List of employees who met the target
        met = []

        # Go through every employee
        for h in hours:

            # Did this employee work enough?
            if h >= target:

                # Save this employee
                met.append(h)

        # The answer is how many we saved
        return len(met)
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | One pass |
| **Space** | `O(n)` | The `met` list can hold everyone |

## 5. Optimal Approach: Just Count

### Idea

1. `count = 0`.
2. For each `h` in `hours`, if `h >= target`, add `1` to `count`.
3. Return `count`.

We never need the list itself, only its size. So a counter is enough.

### Step-by-Step Example

```text
hours = [0, 1, 2, 3, 4], target = 2
count = 0
```

1. `h = 0`. `0 >= 2` is `False`. `count = 0`.
2. `h = 1`. `1 >= 2` is `False`. `count = 0`.
3. `h = 2`. `2 >= 2` is `True`. `count = 0 + 1 = 1`.
4. `h = 3`. `3 >= 2` is `True`. `count = 1 + 1 = 2`.
5. `h = 4`. `4 >= 2` is `True`. `count = 2 + 1 = 3`.

```text
count = 3
```

**Answer: `3`.**

### Code

```python
# Import List for type hints
from typing import List


# Solution for 2798. Number of Employees Who Met the Target
class Solution:

    # Main method
    def numberOfEmployeesWhoMetTarget(self, hours: List[int], target: int) -> int:

        # How many employees met the target
        count = 0

        # Go through every employee
        for h in hours:

            # At least target hours, so equal counts too
            if h >= target:

                # One more employee met the target
                count += 1

        # Return the count
        return count
```

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| Using `>` | Employees with exactly `target` hours are missed | "At least" means `>=` |
| Returning the list of employees | The problem asks for a number | Return `count` |
| Sorting first | Extra `O(n log n)` work for no gain | A single pass is enough |

## 7. Interview Follow-ups

### Q1. Can you write it in one line?

**Answer:**
- `return sum(h >= target for h in hours)`.
- In Python, `True` counts as `1` and `False` as `0`.

### Q2. What if there are many queries with different targets?

**Answer:**
- Sort `hours` once.
- For each target, binary search the first index with `hours[i] >= target`.
- The answer is `n - index`. Each query is `O(log n)`.

### Q3. What if they want the employee numbers, not the count?

**Answer:**
- Keep a list and append `i` when `hours[i] >= target`.
- Space becomes `O(k)`, where `k` is how many met the target.

### Q4. What if hours arrive one at a time, like a stream?

**Answer:**
- Same counter. Add `1` whenever a new value is `>= target`.
- No need to store the stream.

## 8. Interview Explanation

> This is a simple count. I walk through the hours once and add one to a counter every time a value is at least the target. "At least" means greater than or equal, so an employee with exactly the target hours counts. I do not need to store who met it, only how many, so it is O(n) time and O(1) space. If there were many targets to check, I would sort once and binary search for each target instead.
