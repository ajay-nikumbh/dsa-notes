# 09. 283. Move Zeroes

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Easy** | Two Pointers | [283. Move Zeroes](https://leetcode.com/problems/move-zeroes/) | `O(n)` | `O(1)` |

---

## 1. Problem Statement

Given an integer array `nums`, move all `0`'s to the end of it while maintaining the relative order of the non-zero elements.

**Note** that you must do this in-place without making a copy of the array.

### Examples

```text
Example 1:

Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]
```

```text
Example 2:

Input: nums = [0]
Output: [0]
```

### Constraints

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`

### Follow up

Could you minimize the total number of operations done?

### Example

```text
Input:
nums = [0, 1, 0, 3, 12]

Output:
[1, 3, 12, 0, 0]
```

The non-zero elements are:

```text
[1, 3, 12]
```

Their order must remain same.

So we move them to the front and fill the remaining positions with zeroes:

```text
[1, 3, 12, 0, 0]
```

---

## 2. Key Observations

The problem is not asking us to sort the array.

It only asks:

```text
Move zeroes to the end.
Keep non-zero order same.
```

So this is valid:

```text
[0, 1, 0, 3, 12] -> [1, 3, 12, 0, 0]
```

But this is wrong:

```text
[0, 1, 0, 3, 12] -> [12, 3, 1, 0, 0]
```

Because the order of non-zero elements changed.

---

```text
nums = [0]

```

```text
nums = [0, 0, 0]

```

```

```

## 4. Brute Force Solution: Use Extra Array

### Intuition

Create a new array.

First put all non-zero elements into it.

Then add zeroes at the end.

Finally copy the result back into nums.

### Dry Run

```text
nums = [0, 1, 0, 3, 12]
```

Collect non-zero elements:

```text
temp = [1, 3, 12]
```

Number of zeroes:

```text
2
```

Add zeroes:

```text
temp = [1, 3, 12, 0, 0]
```

Copy back:

```text
nums = [1, 3, 12, 0, 0]
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def moveZeroes(self, nums: List[int]) -> None:

        # Create an empty temporary array
        temp = []

        # Traverse every number in nums
        for num in nums:

            # If current number is not zero
            if num != 0:

                # Add it to temp while maintaining order
                temp.append(num)

        # Count how many zeroes need to be added
        zero_count = len(nums) - len(temp)

        # Add all zeroes at the end of temp
        for _ in range(zero_count):

            # Append zero to the temporary array
            temp.append(0)

        # Copy temp back into nums because problem asks in-place modification
        for i in range(len(nums)):

            # Update original nums array
            nums[i] = temp[i]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we traverse the array multiple times, but each traversal is linear. |
| **Space** | `O(n)` | Because we use an extra array `temp`. |

This is not accepted for the follow-up because it asks to do it in-place.

## 5. Better Solution: Shift Non-Zero Elements, Then Fill Zeroes

### Intuition

Instead of making a new array, we can overwrite the same array.

Use a pointer `insert_position`.

This pointer tells us:

```text
Where should the next non-zero element be placed?
```

### Approach

1. Start `insert_position = 0`.
2. Traverse the array.
3. Whenever you find a non-zero number, place it at `nums[insert_position]`.
4. Increase `insert_position`.
5. After all non-zero numbers are placed, fill remaining positions with `0`.

### Dry Run

```text
nums = [0, 1, 0, 3, 12]
```

Initial:

```text
insert_position = 0
```

**i = 0, nums[i] = 0**

Zero found, ignore.

```text
nums = [0, 1, 0, 3, 12]
insert_position = 0
```

**i = 1, nums[i] = 1**

Non-zero found.

Place at `insert_position = 0`.

```text
nums[0] = 1
```

Array becomes:

```text
nums = [1, 1, 0, 3, 12]
insert_position = 1
```

Do not worry about duplicate 1; it will be overwritten later.

**i = 2, nums[i] = 0**

Zero found, ignore.

```text
nums = [1, 1, 0, 3, 12]
insert_position = 1
```

**i = 3, nums[i] = 3**

Place at `insert_position = 1`.

```text
nums[1] = 3
```

Array becomes:

```text
nums = [1, 3, 0, 3, 12]
insert_position = 2
```

**i = 4, nums[i] = 12**

Place at `insert_position = 2`.

```text
nums[2] = 12
```

Array becomes:

```text
nums = [1, 3, 12, 3, 12]
insert_position = 3
```

Now all non-zero values are correctly placed in front:

```text
[1, 3, 12, _, _]
```

Fill remaining positions from index 3 to end with zero:

```text
nums = [1, 3, 12, 0, 0]
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def moveZeroes(self, nums: List[int]) -> None:

        # This pointer stores the position where next non-zero element should be written
        insert_position = 0

        # Traverse every element in the array
        for i in range(len(nums)):

            # If current element is non-zero
            if nums[i] != 0:

                # Place current non-zero element at insert_position
                nums[insert_position] = nums[i]

                # Move insert_position forward for next non-zero element
                insert_position += 1

        # Fill all remaining positions with zero
        for i in range(insert_position, len(nums)):

            # Put zero at the remaining positions
            nums[i] = 0
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we scan the array once and then fill the rest with zeroes. |
| **Space** | `O(1)` | Because we modify the same array. |

## 6. Most Optimal Solution: Two Pointers With Swap

### Why do we need another solution?

The previous solution is already:

```text
Time: O(n)
Space: O(1)
```

But the follow-up asks:

```text
Can you minimize the total number of operations?
```

The previous approach may write many unnecessary values.

Example:

```text
nums = [1, 2, 3]
```

Previous approach does:

```text
nums[0] = 1
nums[1] = 2
nums[2] = 3
```

These are unnecessary writes because the array is already correct.

The swap approach reduces unnecessary writes.

### Core Intuition

Use two pointers:

```text
last_non_zero_position
current
```

`last_non_zero_position` means:

```text
The index where the next non-zero element should go.
```

When we find a non-zero number at index `current`, swap it with `nums[last_non_zero_position]`.

Then increase `last_non_zero_position`.

### Why does this work?

All elements before `last_non_zero_position` are already non-zero and in correct order.

When we find the next non-zero element, we bring it to the next correct position.

Since we scan left to right, the relative order is maintained.

### Dry Run

```text
nums = [0, 1, 0, 3, 12]
```

Initial:

```text
last_non_zero_position = 0
```

**current = 0**

```text
nums[current] = 0
```

It is zero, do nothing.

```text
nums = [0, 1, 0, 3, 12]
last_non_zero_position = 0
```

**current = 1**

```text
nums[current] = 1
```

It is non-zero.

Swap:

```text
nums[0] and nums[1]
```

Array:

```text
[1, 0, 0, 3, 12]
```

Move pointer:

```text
last_non_zero_position = 1
```

**current = 2**

```text
nums[current] = 0
```

It is zero, do nothing.

```text
nums = [1, 0, 0, 3, 12]
last_non_zero_position = 1
```

**current = 3**

```text
nums[current] = 3
```

It is non-zero.

Swap:

```text
nums[1] and nums[3]
```

Array:

```text
[1, 3, 0, 0, 12]
```

Move pointer:

```text
last_non_zero_position = 2
```

**current = 4**

```text
nums[current] = 12
```

It is non-zero.

Swap:

```text
nums[2] and nums[4]
```

Array:

```text
[1, 3, 12, 0, 0]
```

Move pointer:

```text
last_non_zero_position = 3
```

Final:

```text
[1, 3, 12, 0, 0]
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def moveZeroes(self, nums: List[int]) -> None:

        # This pointer tracks where the next non-zero element should be placed
        last_non_zero_position = 0

        # Traverse the array using current index
        for current in range(len(nums)):

            # If current element is non-zero
            if nums[current] != 0:

                # Swap current non-zero element with the element at last_non_zero_position
                nums[last_non_zero_position], nums[current] = nums[current], nums[last_non_zero_position]

                # Move last_non_zero_position forward
                last_non_zero_position += 1
```

### Complexity of Most Optimal Solution

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we traverse the array only once. |
| **Space** | `O(1)` | Because we use only one pointer and modify the array in-place. |

## 7. Small Optimization to Avoid Self-Swap

In the previous code, if array is already like:

```text
[1, 2, 3]
```

Then it swaps every element with itself:

```text
swap nums[0] with nums[0]
swap nums[1] with nums[1]
swap nums[2] with nums[2]
```

This is not logically wrong, but it is unnecessary.

We can avoid this by checking:

```text
if current != last_non_zero_position
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def moveZeroes(self, nums: List[int]) -> None:

        # This pointer stores the next position where a non-zero element should go
        last_non_zero_position = 0

        # Traverse every index of the array
        for current in range(len(nums)):

            # If the current element is non-zero
            if nums[current] != 0:

                # Swap only when current is different from last_non_zero_position
                if current != last_non_zero_position:

                    # Move non-zero element to the correct front position
                    nums[last_non_zero_position], nums[current] = nums[current], nums[last_non_zero_position]

                # Move pointer for the next non-zero element
                last_non_zero_position += 1
```

## 9. Snowball Approach

### Snowball Approach Intuition

Think of every zero as a **snowball**.

As we scan the array from left to right:

```text
Whenever we see 0:
    snowball size increases

Whenever we see non-zero:
    push it left by snowball size
    put 0 at its old place
```

Meaning:

```text
snowball_size = number of zeroes seen so far
```

So if we have already seen 2 zeroes, every next non-zero element should move 2 steps left.

### Example

```text
nums = [0, 1, 0, 3, 12]
```

Initial:

```text
snowball_size = 0
```

**i = 0**

```text
nums[i] = 0
```

Zero found:

```text
snowball_size = 1
```

Array:

```text
[0, 1, 0, 3, 12]
```

**i = 1**

```text
nums[i] = 1
snowball_size = 1
```

Move 1 left by 1 position:

```text
nums[1 - 1] = nums[1]
nums[0] = 1
```

Put zero at current index:

```text
nums[1] = 0
```

Array:

```text
[1, 0, 0, 3, 12]
```

**i = 2**

```text
nums[i] = 0
```

Zero found:

```text
snowball_size = 2
```

Array:

```text
[1, 0, 0, 3, 12]
```

**i = 3**

```text
nums[i] = 3
snowball_size = 2
```

Move 3 left by 2 positions:

```text
nums[3 - 2] = nums[3]
nums[1] = 3
```

Put zero at current index:

```text
nums[3] = 0
```

Array:

```text
[1, 3, 0, 0, 12]
```

**i = 4**

```text
nums[i] = 12
snowball_size = 2
```

Move 12 left by 2 positions:

```text
nums[4 - 2] = nums[4]
nums[2] = 12
```

Put zero at current index:

```text
nums[4] = 0
```

Array:

```text
[1, 3, 12, 0, 0]
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def moveZeroes(self, nums: List[int]) -> None:

        # This variable counts how many zeroes we have seen so far
        snowball_size = 0

        # Traverse the array from left to right
        for i in range(len(nums)):

            # If current element is zero
            if nums[i] == 0:

                # Increase snowball size because we found one more zero
                snowball_size += 1

            # If current element is non-zero and at least one zero exists before it
            elif snowball_size > 0:

                # Move current non-zero element left by snowball_size positions
                nums[i - snowball_size] = nums[i]

                # Put zero at current position
                nums[i] = 0
```

### Snowball Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we traverse the array only once. |
| **Space** | `O(1)` | Because we only use one counter variable. |

## 10. Is Snowball Different From Two Pointer?

Conceptually, both are almost same.

**Two Pointer View**

```text
last_non_zero_position = where next non-zero should go
```

**Snowball View**

```text
snowball_size = how many zeroes are before current index
```

Actually:

```text
last_non_zero_position = current_index - snowball_size
```

So the snowball approach is just another way to think about the same optimized logic.

### Snowball vs Swap Approach

**Swap approach**

```python
nums[last_non_zero_position], nums[current] = nums[current], nums[last_non_zero_position]
```

It swaps non-zero with earliest zero.

**Snowball approach**

```python
nums[i - snowball_size] = nums[i]
nums[i] = 0
```

It shifts the non-zero left and writes zero behind.

### Which one should you use in interview?

Use this one if interviewer asks:

```text
Can you minimize operations?
```
