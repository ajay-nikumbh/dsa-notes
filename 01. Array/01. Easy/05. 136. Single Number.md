# 05. 136. Single Number

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|

---

## 1. Problem Statement

Given a **non-empty** array of integers `nums`, every element appears *twice* except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

### Examples

```text
Example 1:
Input: nums = [2,2,1]
Output: 1

Example 2:
Input: nums = [4,1,2,1,2]
Output: 4

Example 3:
Input: nums = [1]
Output: 1
```

### Constraints

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- Each element in the array appears twice except for one element which appears only once.

---

## 2. Problem Explanation

You are given a **non-empty** integer array nums.

Every element appears exactly **twice**, except for one element that appears exactly **once**.

You need to return that single element.

### Example 1

```text
Input:
nums = [2, 2, 1]

Output:
1
```

Explanation:

```text
2 appears twice
1 appears once
```

So answer is:

```text
1
```

### Example 2

```text
Input:
nums = [4, 1, 2, 1, 2]

Output:
4
```

Explanation:

```text
1 appears twice
2 appears twice
4 appears once
```

So answer is:

```text
4
```

### Example 3

```text
Input:
nums = [1]

Output:
1
```

Only one element exists, so it is the single number.

---

## 3. Key Observation

All numbers appear twice except one.

So we need to find the number whose frequency is 1.

There are multiple approaches:

```text
1. Brute force counting
2. Sorting
3. Hash map / frequency count
4. Mathematical set formula
5. XOR
```

The most optimal one is **XOR**.

---

## 4. Brute Force Solution

### Intuition

For every element, count how many times it appears in the array.

The element whose count is 1 is the answer.

### Approach

1. Pick each element.
2. Count its frequency by scanning the whole array.
3. If frequency is 1, return that element.

### Dry Run

```text
nums = [4, 1, 2, 1, 2]
```

Check 4:

```text
4 appears 1 time
```

So answer is:

```text
4
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def singleNumber(self, nums: List[int]) -> int:

        # Traverse every number one by one
        for i in range(len(nums)):

            # Count how many times nums[i] appears
            count = 0

            # Compare nums[i] with every number in nums
            for j in range(len(nums)):

                # If both values are equal
                if nums[j] == nums[i]:

                    # Increase occurrence count
                    count += 1

            # If current number appears exactly once
            if count == 1:

                # Return the single number
                return nums[i]

        # This line will never be reached for valid input
        return -1
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | Because for every element, we scan the full array. |
| **Space** | `O(1)` | Because we only use variables. |

## 5. Better Solution: Sorting

### Intuition

If we sort the array, duplicate numbers will come next to each other.

Then we can check elements in pairs.

Example:

```text
nums = [4, 1, 2, 1, 2]
```

After sorting:

```text
[1, 1, 2, 2, 4]
```

Now pairs are:

```text
1, 1
2, 2
```

The leftover unpaired element is:

```text
4
```

### Approach

1. Sort the array.
2. Traverse with step size 2.
3. If `nums[i] != nums[i + 1]`, then `nums[i]` is single.
4. If all pairs match, the last element is single.

### Dry Run

```text
nums = [4, 1, 2, 1, 2]
```

Sort:

```text
[1, 1, 2, 2, 4]
```

Check pair at index 0 and 1:

```text
1 == 1
```

Check pair at index 2 and 3:

```text
2 == 2
```

Now only last element remains:

```text
4
```

Answer:

```text
4
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def singleNumber(self, nums: List[int]) -> int:

        # Sort the array so equal elements come together
        nums.sort()

        # Traverse array in pairs
        for i in range(0, len(nums) - 1, 2):

            # If current pair is not equal
            if nums[i] != nums[i + 1]:

                # Current element is the single number
                return nums[i]

        # If all pairs matched, the last element is single
        return nums[-1]
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n log n)` | Because sorting takes `O(n log n)`. |
| **Space** | `O(1)` or `O(n)` | Depending on sorting implementation. |

## 6. Better Solution: Hash Map / Frequency Count

### Intuition

Store how many times each number appears.

Then return the number whose frequency is 1.

### Approach

1. Create a dictionary.
2. Count frequency of every number.
3. Traverse dictionary.
4. Return the key whose value is 1.

### Dry Run

```text
nums = [4, 1, 2, 1, 2]
```

Frequency map:

```text
4 -> 1
1 -> 2
2 -> 2
```

The number with frequency 1 is:

```text
4
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def singleNumber(self, nums: List[int]) -> int:

        # Create an empty dictionary to store frequencies
        frequency = {}

        # Traverse every number in nums
        for num in nums:

            # If number is already present in dictionary
            if num in frequency:

                # Increase its count
                frequency[num] += 1

            # If number is appearing for the first time
            else:

                # Initialize its count as 1
                frequency[num] = 1

        # Traverse all key-value pairs in dictionary
        for num, count in frequency.items():

            # If current number appears exactly once
            if count == 1:

                # Return this number
                return num

        # This line will never be reached for valid input
        return -1
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we scan the array once and dictionary once. |
| **Space** | `O(n)` | Because we may store many numbers in the dictionary. |

## 7. Better Solution: Set Mathematical Formula

### Intuition

Since every duplicate appears exactly twice:

```text
2 * sum(unique elements) - sum(all elements)
```

will give the single number.

### Why This Works

Example:

```text
nums = [4, 1, 2, 1, 2]
```

Unique elements:

```text
{4, 1, 2}
```

Sum of unique elements:

```text
4 + 1 + 2 = 7
```

Double it:

```text
2 * 7 = 14
```

Sum of all elements:

```text
4 + 1 + 2 + 1 + 2 = 10
```

Difference:

```text
14 - 10 = 4
```

Answer:

```text
4
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def singleNumber(self, nums: List[int]) -> int:

        # Convert nums to set to keep only unique values
        unique_values = set(nums)

        # Calculate twice the sum of all unique values
        twice_unique_sum = 2 * sum(unique_values)

        # Calculate sum of all values in nums
        total_sum = sum(nums)

        # Difference gives the single number
        return twice_unique_sum - total_sum
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we scan the array to build the set and the sums. |
| **Space** | `O(n)` | Because the set stores unique elements. |

## 8. Most Optimal Solution: XOR

### Core Intuition

XOR is the best solution here.

The idea is:

```text
Same numbers cancel each other.
Only the single number remains.
```

### XOR Properties

You need to remember these three rules:

```text
a ^ a = 0
```

Any number XOR with itself becomes 0.

Example:

```text
5 ^ 5 = 0
```

Second rule:

```text
a ^ 0 = a
```

Any number XOR with zero remains same.

Example:

```text
7 ^ 0 = 7
```

Third rule:

```text
XOR order does not matter.
```

Example:

```text
a ^ b ^ a = a ^ a ^ b = 0 ^ b = b
```

---

## 9. XOR Dry Run

```text
nums = [4, 1, 2, 1, 2]
```

Initialize:

```text
answer = 0
```

Now XOR each number:

| Step | num | answer calculation | answer |
|:---:|:---:|:---:|:---:|
| 1 | 4 | `0 ^ 4` | 4 |
| 2 | 1 | `4 ^ 1` | 5 |
| 3 | 2 | `5 ^ 2` | 7 |
| 4 | 1 | `7 ^ 1` | 6 |
| 5 | 2 | `6 ^ 2` | 4 |

Final answer:

```text
4
```

### Easier Cancellation View

```text
4 ^ 1 ^ 2 ^ 1 ^ 2
```

Rearrange because XOR order does not matter:

```text
(1 ^ 1) ^ (2 ^ 2) ^ 4
```

Duplicates cancel:

```text
0 ^ 0 ^ 4
```

Final:

```text
4
```

## 10. Why XOR Handles Negative Numbers Also

XOR works on binary representation.

Even if numbers are negative, duplicates still cancel:

```text
-1 ^ -1 = 0
```

So if:

```text
nums = [-1, 2, 2]
```

Then:

```text
-1 ^ 2 ^ 2 = -1
```

Answer:

```text
-1
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def singleNumber(self, nums: List[int]) -> int:

        # Initialize answer with 0 because x ^ 0 = x
        answer = 0

        # Traverse every number in the array
        for num in nums:

            # XOR current number with answer
            # Duplicate numbers cancel out
            answer ^= num

        # The remaining value is the single number
        return answer
```

| **Space** | `O(1)` | Because we only use one variable. |

## 12. Interview Explanation

You can say:

> Since every element appears twice except one, I can use XOR. XOR of two same numbers becomes zero, and XOR with zero gives the number itself. So when I XOR all elements, all duplicate pairs cancel out, and the only remaining value is the single number. This gives `O(n)` time and `O(1)` space.
