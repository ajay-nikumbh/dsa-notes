## 1. Problem Statement

Given an array `nums` containing `n` distinct numbers in the range `[0, n]`, return *the only number in the range that is missing from the array*.

### Examples

```text
Example 1:
Input: nums = [3,0,1]
Output: 2
Explanation: n = 3 since there are 3 numbers, so all numbers are in the range [0,3]. 2 is the missing number in the range since it does not appear in nums.

Example 2:
Input: nums = [0,1]
Output: 2
Explanation: n = 2 since there are 2 numbers, so all numbers are in the range [0,2]. 2 is the missing number in the range since it does not appear in nums.

Example 3:
Input: nums = [9,6,4,2,3,5,7,0,1]
Output: 8
Explanation: n = 9 since there are 9 numbers, so all numbers are in the range [0,9]. 8 is the missing number in the range since it does not appear in nums.
```

### Constraints

- `n == nums.length`
- `1 <= n <= 10^4`
- `0 <= nums[i] <= n`
- All the numbers of `nums` are **unique**.

**Follow up:** Could you implement a solution using only `O(1)` extra space complexity and `O(n)` runtime complexity?

## 4. Brute Force Solution: Check Every Number

### Intuition

The missing number must be somewhere between 0 and n.

So for every number from 0 to n, check whether it exists in the array.

The first number that does not exist is the answer.

### Approach

1. Let `n = len(nums)`.
2. For every number `target` from 0 to n:
   - Search for `target` inside `nums`.
   - If not found, return `target`.

### Dry Run

```text
nums = [3, 0, 1]
n = 3
```

Check numbers from 0 to 3.

| target | Present in nums? |
|:---:|:---:|
| 0 | Yes |
| 1 | Yes |
| 2 | No |

So answer is:

```text
2
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def missingNumber(self, nums: List[int]) -> int:

        # Store the length of the array
        n = len(nums)

        # Check every possible number from 0 to n
        for target in range(n + 1):

            # Assume current target is not present initially
            found = False

            # Search current target inside the array
            for num in nums:

                # If current array element equals target
                if num == target:

                    # Mark target as found
                    found = True

                    # Stop searching because target exists
                    break

            # If target was not found in the array
            if not found:

                # This is the missing number
                return target

        # This line will never be reached for valid input
        return -1
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n^2)` | Because for every number from 0 to n, we may scan the whole array. |
| **Space** | `O(1)` | Because we use only variables. |

## 5. Better Solution: Sorting

### Intuition

If the array is sorted, then every number should appear at its correct index.

For a complete range:

```text
[0, 1, 2, 3]
```

Every value is equal to its index:

```text
index 0 -> value 0
index 1 -> value 1
index 2 -> value 2
index 3 -> value 3
```

If one number is missing, after sorting, the first index where:

```text
nums[i] != i
```

is the missing number.

### Dry Run

```text
nums = [3, 0, 1]
```

Sort:

```text
nums = [0, 1, 3]
```

Now compare index and value:

| index | nums[index] | Correct? |
|:---:|:---:|:---:|
| 0 | 0 | Yes |
| 1 | 1 | Yes |
| 2 | 3 | No |

At index 2, value should have been 2.

So missing number is:

```text
2
```

### Important Case: Missing Number Is n

```text
nums = [0, 1, 2]
n = 3
```

Sorted:

```text
[0, 1, 2]
```

Every index matches.

So missing number is:

```text
3
```

That means if no mismatch is found, return n.

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def missingNumber(self, nums: List[int]) -> int:

        # Sort the array in ascending order
        nums.sort()

        # Traverse every index of the sorted array
        for i in range(len(nums)):

            # If value is not equal to its expected index
            if nums[i] != i:

                # Then index i is the missing number
                return i

        # If all indices matched, then missing number is n
        return len(nums)
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n log n)` | Because sorting takes `O(n log n)`. |
| **Space** | `O(1)` or `O(n)` | Depending on sorting implementation. |

## 6. Better Solution: Hash Set

### Intuition

Searching in an array takes `O(n)` time.

But searching in a set takes average `O(1)` time.

So we can store all numbers in a set, then check which number from 0 to n is missing.

### Approach

1. Convert nums into a set.
2. Check every number from 0 to n.
3. Return the number not present in the set.

### Dry Run

```text
nums = [3, 0, 1]
```

Create set:

```text
seen = {0, 1, 3}
```

Check:

```text
0 in seen? Yes
1 in seen? Yes
2 in seen? No
```

Answer:

```text
2
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def missingNumber(self, nums: List[int]) -> int:

        # Convert array into set for fast lookup
        seen = set(nums)

        # Store the length of the array
        n = len(nums)

        # Check every number from 0 to n
        for number in range(n + 1):

            # If current number is not present in set
            if number not in seen:

                # Current number is missing
                return number

        # This line will never be reached for valid input
        return -1
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because creating the set takes `O(n)` and checking range also takes `O(n)`. |
| **Space** | `O(n)` | Because we store all numbers in a set. |

## 7. Most Optimal Solution 1: Sum Formula

### Core Intuition

We know the sum of numbers from 0 to n.

Formula:

```text
expected_sum = n * (n + 1) // 2
```

Then calculate actual sum of array.

The missing number is:

```text
expected_sum - actual_sum
```

### Why This Works

Example:

```text
nums = [3, 0, 1]
n = 3
```

Expected numbers:

```text
0, 1, 2, 3
```

Expected sum:

```text
0 + 1 + 2 + 3 = 6
```

Actual sum:

```text
3 + 0 + 1 = 4
```

Missing number:

```text
6 - 4 = 2
```

### Formula Derivation Intuition

Sum of first n natural numbers:

```text
1 + 2 + 3 + ... + n
```

Pair first and last:

```text
1 + n = n + 1
2 + (n - 1) = n + 1
3 + (n - 2) = n + 1
```

There are `n / 2` such pairs.

So total sum is:

```text
n * (n + 1) / 2
```

Since range starts from 0, adding 0 does not change the sum.

So:

```text
0 + 1 + 2 + ... + n = n * (n + 1) / 2
```

### Dry Run

```text
nums = [9,6,4,2,3,5,7,0,1]
```

Array length:

```text
n = 9
```

Expected sum:

```text
9 * 10 // 2 = 45
```

Actual sum:

```text
9 + 6 + 4 + 2 + 3 + 5 + 7 + 0 + 1 = 37
```

Missing:

```text
45 - 37 = 8
```

Answer:

```text
8
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def missingNumber(self, nums: List[int]) -> int:

        # Store the length of the array
        n = len(nums)

        # Calculate expected sum from 0 to n using formula
        expected_sum = n * (n + 1) // 2

        # Calculate actual sum of elements present in nums
        actual_sum = 0

        # Traverse every number in nums
        for num in nums:

            # Add current number to actual sum
            actual_sum += num

        # Difference between expected and actual sum is missing number
        return expected_sum - actual_sum
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we traverse the array once to compute the actual sum. |
| **Space** | `O(1)` | Because we only use variables. |

## 8. Most Optimal Solution 2: XOR

### Core Intuition

XOR has three important properties:

```text
a ^ a = 0
a ^ 0 = a
XOR is commutative and associative
```

Meaning if we XOR all numbers from 0 to n and XOR all numbers in nums, all matching numbers cancel out.

Only the missing number remains.

### Simple Example

```text
nums = [3, 0, 1]
```

Expected range:

```text
0, 1, 2, 3
```

Array has:

```text
3, 0, 1
```

Now XOR them all:

```text
0 ^ 1 ^ 2 ^ 3 ^ 3 ^ 0 ^ 1
```

Rearrange matching pairs:

```text
(0 ^ 0) ^ (1 ^ 1) ^ (3 ^ 3) ^ 2
```

Matching pairs become zero:

```text
0 ^ 0 ^ 0 ^ 2
```

Final:

```text
2
```

### Dry Run with XOR

```text
nums = [3, 0, 1]
n = 3
```

Initialize:

```text
xor_value = 0
```

We XOR indices and values together.

| i | nums[i] | xor_value calculation |
|:---:|:---:|:---:|
| 0 | 3 | `0 ^ 0 ^ 3 = 3` |
| 1 | 0 | `3 ^ 1 ^ 0 = 2` |
| 2 | 1 | `2 ^ 2 ^ 1 = 1` |

Now XOR with n:

```text
xor_value = 1 ^ 3 = 2
```

Answer:

```text
2
```

### Code

```python
# Define the class solution
class Solution:

    # Define the method
    def missingNumber(self, nums: List[int]) -> int:

        # Store the length of the array
        n = len(nums)

        # Initialize xor_value with n because range includes 0 to n
        xor_value = n

        # Traverse each index and value
        for i in range(n):

            # XOR current index and current number
            # All common values cancel out eventually
            xor_value = xor_value ^ i ^ nums[i]

        # Remaining value is the missing number
        return xor_value
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n)` | Because we traverse the array once. |
| **Space** | `O(1)` | Because we only use one variable. |

## 9. Which Optimal Solution Should You Use?

Both are optimal:

```text
Sum Formula:
Time: O(n)
Space: O(1)

XOR:
Time: O(n)
Space: O(1)
```

### In Python

Use sum formula because Python integers do not overflow.

```python
return n * (n + 1) // 2 - sum(nums)
```

### In Java/C++ Interviews

XOR is safer because integer sum can overflow for very large constraints.

For LeetCode constraints, both are fine.
