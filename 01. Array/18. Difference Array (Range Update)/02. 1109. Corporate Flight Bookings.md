# 02. 1109. Corporate Flight Bookings

| Difficulty | Pattern | Source | Time | Space |
|:---:|:---:|:---:|:---:|:---:|
| **Medium** | Difference Array (Range Update) | [1109. Corporate Flight Bookings](https://leetcode.com/problems/corporate-flight-bookings/) | `O(n + k)` | `O(n)` |

## 1. Problem Statement

There are `n` flights, labeled `1` to `n`.

You get a list `bookings`. Each `bookings[i] = [first, last, seats]` books `seats` seats on **every** flight from `first` to `last` (both included).

Return an array `answer` of length `n`, where `answer[i]` is the total seats booked on flight `i + 1`.

### Example

```text
n = 5
bookings = [[1, 2, 10], [2, 3, 20], [2, 5, 25]]

Flight:          1    2    3    4    5
Booking 1:      10   10
Booking 2:           20   20
Booking 3:           25   25   25   25
                ---  ---  ---  ---  ---
Total:          10   55   45   25   25

Output: [10, 55, 45, 25, 25]
```

We use this same example in every section below.

### Constraints

- `1 <= n <= 2 * 10^4`
- `1 <= bookings.length <= 2 * 10^4`
- `bookings[i].length == 3`
- `1 <= first <= last <= n`
- `1 <= seats <= 10^4`

## 2. Core Theory

### What the problem really asks

Each booking is "add `seats` to a range of flights". We want the totals at the end.

That is exactly [01. 370. Range Addition](./01.%20370.%20Range%20Addition.md) (which explains the difference array from scratch), with two small changes:

- Flights are **1-indexed**. Flight `f` is at index `f - 1`.
- The update is called `seats` instead of `inc`.

### Index mapping

For a booking `[first, last, seats]`:

- The change starts at flight `first`, which is index `first - 1`. So `diff[first - 1] += seats`.
- The change stops after flight `last`. The next index is `(last - 1) + 1 = last`. So `diff[last] -= seats`.

```text
Booking [2, 3, 20], n = 5

flight:   1    2    3    4    5    (past end)
index:    0    1    2    3    4    5
diff:    [0] [+20]  [0] [-20] [0]  [0]
               ^         ^
       index first-1   index last
```

`last` can be `n`, so `diff` needs `n + 1` cells.

## 3. Edge Cases

| Case | Input | Expected | Why it matters |
|:---|:---|:---:|:---|
| One flight | `n = 1, [[1, 1, 7]]` | `[7]` | `diff[1]` is the extra cell |
| Booking covers all flights | `n = 3, [[1, 3, 4]]` | `[4, 4, 4]` | Stop mark goes in the extra cell |
| Same booking twice | `n = 2, [[1, 2, 5], [1, 2, 5]]` | `[10, 10]` | Marks add up |
| Single-flight bookings | `n = 3, [[2, 2, 9]]` | `[0, 9, 0]` | Start and stop are next to each other |
| Flight with no booking | `n = 3, [[1, 1, 1], [3, 3, 1]]` | `[1, 0, 1]` | Running sum drops back to 0 |

## 4. Brute Force: Add to Every Flight

### Idea

For each booking, loop over flights `first..last` and add `seats`.

### Code

```python
# Import List for type hints
from typing import List


# Brute force: touch every flight of every booking
class SolutionBrute:

    # Main method
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:

        # Seats per flight, index 0 = flight 1
        answer = [0] * n

        # Apply each booking
        for first, last, seats in bookings:

            # Walk the flights in the booking
            for f in range(first, last + 1):

                # Flight f is at index f - 1
                answer[f - 1] += seats

        # Return the totals
        return answer
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n * k)` | Each of `k` bookings can cover `n` flights |
| **Space** | `O(1)` extra | Only the output |

## 5. Optimal Approach: Difference Array

### Idea

1. `diff` of size `n + 1`, all zeros.
2. For each booking: `diff[first - 1] += seats`, `diff[last] -= seats`.
3. Running sum over `0..n-1` gives the answer.

### Visual Walkthrough (Story Version)

Before the arrays, let us see the idea as a story.

**The story:** an airline has 5 planes leaving one after another, flight 1 to flight 5. A travel agent books groups that ride several flights in a row. Instead of writing the group on every flight's list, the agent sticks a **"group gets on"** note on the first flight and a **"group got off"** note on the flight right after their last one. At the end of the day, a clerk walks past the flights in order, keeping a count of how many people are on board.

**The rules:**

- Booking `[first, last, seats]`: put `+seats` on flight `first`, put `-seats` on flight `last + 1`.
- Flight `6` does not exist, but we keep a spare note board for it.
- The clerk's count at each flight = count so far + that flight's note.

**How to read the pictures:** `F1..F5` = flights, `spare` = board after the last flight. `^` = where a note was just put.

**Start: no notes**

```text
board:   F1    F2    F3    F4    F5   spare
notes:  [0]   [0]   [0]   [0]   [0]   [0]
```

**Booking 1: `[1, 2, 10]`** — 10 people ride flights 1 and 2.

- `+10` on F1. `-10` on F3.

```text
board:   F1    F2    F3    F4    F5   spare
notes:  [+10] [0]   [-10] [0]   [0]   [0]
         ^           ^
```

**Booking 2: `[2, 3, 20]`** — 20 people ride flights 2 and 3.

- `+20` on F2. `-20` on F4.

```text
board:   F1    F2    F3    F4    F5   spare
notes:  [+10] [+20] [-10] [-20] [0]   [0]
               ^           ^
```

**Booking 3: `[2, 5, 25]`** — 25 people ride flights 2 to 5.

- `+25` on F2 (now `+45`). `-25` on the spare board.

```text
board:   F1    F2    F3    F4    F5   spare
notes:  [+10] [+45] [-10] [-20] [0]   [-25]
               ^                       ^
```

**The clerk's walk**

```text
F1: count = 0 + 10 = 10
notes:  [+10] [+45] [-10] [-20] [0]
         ^
seats:  [10]

F2: count = 10 + 45 = 55
notes:  [+10] [+45] [-10] [-20] [0]
               ^
seats:  [10]  [55]

F3: count = 55 - 10 = 45
notes:  [+10] [+45] [-10] [-20] [0]
                     ^
seats:  [10]  [55]  [45]

F4: count = 45 - 20 = 25
notes:  [+10] [+45] [-10] [-20] [0]
                           ^
seats:  [10]  [55]  [45]  [25]

F5: count = 25 + 0 = 25
notes:  [+10] [+45] [-10] [-20] [0]
                                 ^
seats:  [10]  [55]  [45]  [25]  [25]
```

The spare board is never walked. Answer: `[10, 55, 45, 25, 25]`.

**All steps at a glance**

| Step | What happens | Notes (`diff`) | Seats so far |
|:---:|:---|:---|:---|
| Booking 1 | `+10` at index 0, `-10` at index 2 | `[10, 0, -10, 0, 0, 0]` | – |
| Booking 2 | `+20` at index 1, `-20` at index 3 | `[10, 20, -10, -20, 0, 0]` | – |
| Booking 3 | `+25` at index 1, `-25` at index 5 | `[10, 45, -10, -20, 0, -25]` | – |
| Walk F1 | count `10` | – | `[10]` |
| Walk F2 | count `55` | – | `[10, 55]` |
| Walk F3 | count `45` | – | `[10, 55, 45]` |
| Walk F4 | count `25` | – | `[10, 55, 45, 25]` |
| Walk F5 | count `25` | – | `[10, 55, 45, 25, 25]` |

**What the story teaches**

| In the story | In the code |
|:---|:---|
| Flight `f` | Index `f - 1` |
| "Group gets on" note | `diff[first - 1] += seats` |
| "Group got off" note on the next flight | `diff[last] -= seats` |
| Spare board | Extra cell `diff[n]` |
| Clerk's count | `running += diff[i]` |
| People on flight `f` | `answer[f - 1]` |

Now the same steps again, this time with the exact arrays.

### Step-by-Step Example

```text
n = 5
bookings = [[1, 2, 10], [2, 3, 20], [2, 5, 25]]
diff = [0, 0, 0, 0, 0, 0]   (size 6)
```

**Phase 1: mark the bookings**

| Booking | `diff[first - 1] += seats` | `diff[last] -= seats` | `diff` after |
|:---:|:---|:---|:---|
| `[1, 2, 10]` | `diff[0] = 0 + 10 = 10` | `diff[2] = 0 - 10 = -10` | `[10, 0, -10, 0, 0, 0]` |
| `[2, 3, 20]` | `diff[1] = 0 + 20 = 20` | `diff[3] = 0 - 20 = -20` | `[10, 20, -10, -20, 0, 0]` |
| `[2, 5, 25]` | `diff[1] = 20 + 25 = 45` | `diff[5] = 0 - 25 = -25` | `[10, 45, -10, -20, 0, -25]` |

**Phase 2: running sum**

| `i` | `diff[i]` | `running` before | `running` after | `answer` |
|:---:|:---:|:---:|:---:|:---|
| 0 | 10 | 0 | 10 | `[10, 0, 0, 0, 0]` |
| 1 | 45 | 10 | 55 | `[10, 55, 0, 0, 0]` |
| 2 | -10 | 55 | 45 | `[10, 55, 45, 0, 0]` |
| 3 | -20 | 45 | 25 | `[10, 55, 45, 25, 0]` |
| 4 | 0 | 25 | 25 | `[10, 55, 45, 25, 25]` |

**Answer: `[10, 55, 45, 25, 25]`.**

### Code

```python
# Optimal: difference array plus one running sum
class Solution:

    # Main method
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:

        # One extra cell for diff[last] when last == n
        diff = [0] * (n + 1)

        # Mark every booking in O(1)
        for first, last, seats in bookings:

            # Seats start at flight first (index first - 1)
            diff[first - 1] += seats

            # Seats stop after flight last (index last)
            diff[last] -= seats

        # Seats per flight
        answer = [0] * n

        # Seats active at the current flight
        running = 0

        # Walk the flights in order
        for i in range(n):

            # Add this flight's mark
            running += diff[i]

            # Total seats on flight i + 1
            answer[i] = running

        # Return the totals
        return answer
```

### Complexity

| Measure | Complexity | Why |
|:---|:---:|:---|
| **Time** | `O(n + k)` | `O(1)` per booking, one pass over `n` flights |
| **Space** | `O(n)` | The `diff` array (plus the output) |

## 6. Common Mistakes

| Mistake | What goes wrong | Fix |
|:---|:---|:---|
| `diff[first] += seats` (forgetting 1-indexing) | Every booking starts one flight late | Use `first - 1` |
| `diff[last + 1] -= seats` | Booking stops one flight late, and can go out of range | 1-indexed `last` is already the next 0-indexed spot |
| `diff` of size `n` | `diff[n]` crashes when `last == n` | Size `n + 1` |
| Returning `diff` | Not the totals | Take the running sum |
| Argument order `(n, bookings)` | LeetCode passes `(bookings, n)` | Match the signature |

## 7. Interview Follow-ups

### Q1. How is this different from Range Addition?

**Answer:**
- Same idea. Only the indexing changes: flights are 1-indexed.
- Start mark at `first - 1`, stop mark at `last`.

### Q2. What if the airline asks for seat counts while bookings are still coming in?

**Answer:**
- Use a Fenwick tree over the difference array.
- Booking = two point updates. "Seats on flight `f`" = prefix sum up to `f`. Both `O(log n)`.

### Q3. What if a booking can be cancelled?

**Answer:**
- A cancellation is the same booking with negative seats.
- `diff[first - 1] -= seats`, `diff[last] += seats`.

### Q4. What if `n` is `10^9` but there are only a few bookings?

**Answer:**
- Store marks in a dictionary keyed by index.
- Sort the keys and sweep. Report totals per segment instead of per flight.

### Q5. Can we skip the extra `diff` array?

**Answer:**
- Yes. Use `answer` itself as the difference array (skip the stop mark when `last == n`), then prefix-sum it in place.

## 8. Interview Explanation

> Each booking adds the same number of seats to a range of flights, so it is a range update. Instead of looping over every flight, I keep a difference array of size n plus 1. For a booking first, last, seats, I add seats at index first minus 1 and subtract seats at index last, because flights are 1-indexed. Then a single running sum from left to right gives the total seats on each flight. That is O(n plus k) time and O(n) space instead of O(n times k).
